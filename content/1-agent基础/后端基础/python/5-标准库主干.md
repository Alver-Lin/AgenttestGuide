## 25｜文本、数据与时间

### 25.1 文本处理：先用字符串方法，再考虑正则

固定分隔符用 `split()`，固定替换用 `replace()`；当输入具有可描述的模式时，再用 `re`。

```python
import re

line = "name=小林 score=85"
pattern = r"name=(?P<name>\S+)\s+score=(?P<score>\d+)"
match = re.fullmatch(pattern, line)
if match is None:
    raise ValueError("记录格式不正确")
print(match.group("name"))
print(int(match.group("score")))
print(re.search(r"\d+", "没有分数") is None)
```

```text
小林
85
True
```

- `search()` 在任意位置寻找匹配，`fullmatch()` 要求整个字符串符合模式。
- `r"..."` 是原始字符串，减少反斜杠转义的干扰。
- `(?P<name>...)` 是命名分组；匹配失败得到 `None`，不能直接调用 `.group()`。
- 正则确认的是文本形状。数字提取成功后，仍要检查分数是否在 0–100 内。

不要用一个巨大正则解析完整 HTML、JSON 或任意嵌套结构。这些格式有专用解析器。

### 25.2 CSV：让解析器处理引号与逗号

```python
import csv
import io

source = io.StringIO('name,score\n"小林,一组",85\n小周,58\n')
records = list(csv.DictReader(source))
print(records[0]["name"])
print(sum(int(row["score"]) for row in records))

output = io.StringIO(newline="")
writer = csv.DictWriter(output, fieldnames=["name", "score"])
writer.writeheader()
writer.writerow({"name": "小陈", "score": 92})
print(output.getvalue().splitlines())
```

```text
小林,一组
143
['name,score', '小陈,92']
```

CSV 读出的字段默认是字符串，空字符串也不会自动变成 `None`。读取真实文件用 `open(path, encoding="utf-8", newline="")`，由 `csv` 处理换行。不要自己用 `line.split(",")` 拆 CSV，因为被引号包住的字段内部也可能有逗号。

### 25.3 日期、时刻与时长是不同概念

`date` 表示日历日期，`datetime` 表示日期和时间，`timedelta` 表示时长。跨地区存储或比较时刻时，应约定时区。

```python
from datetime import datetime, timedelta, timezone

utc_time = datetime.fromisoformat("2026-11-18T08:00:00+00:00")
china_time = utc_time.astimezone(timezone(timedelta(hours=8)))
print(china_time.isoformat())
print((utc_time + timedelta(minutes=30)).isoformat())
print(utc_time == china_time)
```

```text
2026-11-18T16:00:00+08:00
2026-11-18T08:30:00+00:00
True
```

这两个对象的显示不同，但表示同一时刻。带时区的时间称为 aware datetime；不带时区的时间称为 naive datetime。两者不要混着做大小比较。

固定 `+08:00` 偏移只表达偏移量。涉及历史规则或夏令时，用 `zoneinfo.ZoneInfo("Asia/Shanghai")` 这样的地区时区；环境需要可用的时区数据库。`replace(tzinfo=...)` 是附加或替换时区标签，不能代替转换时刻的 `astimezone()`。

测量函数执行耗时用 `time.perf_counter()`，因为墙上时钟可能被校准。时间字符串的解析格式、存储时区、展示时区，应成为项目约定。

### 25.4 配置、压缩和摘要

`tomllib` 从 Python 3.11 起属于标准库，用于读取 TOML；它不提供写入接口。

```python
import hashlib
import tomllib

config = tomllib.loads('[report]\nthreshold = 60\ntitle = "成绩报告"\n')
print(config["report"]["threshold"])

content = "测评记录".encode("utf-8")
digest = hashlib.sha256(content).hexdigest()
print(len(digest))
print(digest == hashlib.sha256(content).hexdigest())
```

```text
60
64
True
```

真实 TOML 文件可以用 `open(path, "rb")` 加 `tomllib.load()`。配置被解析后仍需验证类型和取值。

其他按需查找的工具：`configparser` 读取 INI；`gzip` 压缩单个数据流；`zipfile` 管理 ZIP；`hashlib` 做内容摘要；`difflib` 比较文本。摘要可辅助判断内容是否变化，但普通 SHA-256 不是直接存储用户密码的方案。

**练习**：把含姓名、分数和带时区时间的 CSV 转成记录列表，拒绝非法分数，统一以 UTC 保存时间。

**掌握标志**：能区分格式解析与业务校验，能解释 CSV 的引号、时间的时区、配置的类型。

## 26｜集合与算法

### 26.1 用专门容器表达意图

```python
from collections import Counter, defaultdict, deque

subjects = ["Python", "SQL", "Python"]
print(Counter(subjects).most_common(1))

by_subject = defaultdict(list)
for subject, score in [("Python", 85), ("SQL", 58), ("Python", 92)]:
    by_subject[subject].append(score)
print(dict(by_subject))

queue = deque(["任务A", "任务B"])
queue.append("任务C")
print(queue.popleft())
print(list(queue))
```

```text
[('Python', 2)]
{'Python': [85, 92], 'SQL': [58]}
任务A
['任务B', '任务C']
```

`Counter` 负责计数；`defaultdict(list)` 为缺失键自动创建列表；`deque` 适合两端增删。列表头部 `pop(0)` 要移动后续元素，队列需求优先考虑 `deque.popleft()`。

注意：读取 `defaultdict` 的缺失键会插入默认值；只想查询、不想改变容器时，用 `.get()`。多线程生产者与消费者之间的阻塞队列，放到 L6 学 `queue.Queue`。

### 26.2 堆：反复取当前最小值

```python
import heapq

jobs = []
heapq.heappush(jobs, (2, 0, "普通报告"))
heapq.heappush(jobs, (1, 1, "紧急报告"))
heapq.heappush(jobs, (1, 2, "另一份紧急报告"))
print([heapq.heappop(jobs)[2] for _ in range(3)])
print(heapq.nlargest(2, [85, 58, 92, 0]))
```

```text
['紧急报告', '另一份紧急报告', '普通报告']
[92, 85]
```

`heapq` 默认维护最小堆；堆顶最小，整个列表不保证完全排序。三元组中的递增序号用于相同优先级的稳定排序，也避免继续比较不能排序的任务对象。

如果只需要完整排序一次，直接用 `sorted()` 更清楚；需要不断加入任务并取优先级最高的一项，才适合堆。

### 26.3 二分查找：输入必须有序

```python
from bisect import bisect_left, bisect_right, insort

scores = [58, 60, 60, 85]
print(bisect_left(scores, 60))
print(bisect_right(scores, 60))
insort(scores, 75)
print(scores)
```

```text
1
3
[58, 60, 60, 75, 85]
```

`bisect_left()` 给出插入到相等元素左侧的位置，返回位置不等于“已经找到相等元素”；需要检查索引是否越界、该元素是否相等。查找位置是对数级比较，但列表插入仍要移动元素，整体插入不是对数复杂度。

数值场景再查 `math`、`statistics`、`decimal`、`fractions`；随机抽样用 `random`，测试时可以创建独立的 `random.Random(种子)`，避免改变全局随机状态。

**练习**：统计各科记录数，维护最近 10 条记录，再用堆取最高的 3 个分数。说明各处为什么选择对应容器。

**掌握标志**：能根据访问和修改方式选容器，知道有序列表、堆和普通列表的差别。

## 27｜网络与 Web

### 27.1 URL 是结构化数据

```python
from urllib.parse import parse_qs, urlencode, urlsplit

query = urlencode({"keyword": "Python 入门", "page": 1})
url = "https://example.com/search?" + query
parts = urlsplit(url)
print(parts.scheme)
print(parts.netloc)
print(parse_qs(parts.query))
```

```text
https
example.com
{'keyword': ['Python 入门'], 'page': ['1']}
```

查询参数用 `urlencode()` 编码。路径片段的转义是另一件事，可用 `quote()`；不要把整个 URL 都当作一个路径片段转义。

`urlsplit()` 负责拆解，不代表地址已经通过业务校验。如果程序只允许访问固定站点，需要另外约束协议和主机。

### 27.2 HTTP：区分请求、响应与业务数据

下面的函数默认可以使用 `urlopen`，示例通过传入模拟函数离线验证解析逻辑。

```python
import io
import json
from urllib.request import Request, urlopen


def fetch_json(url, *, opener=urlopen):
    request = Request(url, headers={"Accept": "application/json"})
    with opener(request, timeout=5) as response:
        raw = response.read(100_001)
    if len(raw) > 100_000:
        raise ValueError("响应超过示例允许的大小")
    return json.loads(raw.decode("utf-8"))


def fake_open(request, timeout):
    assert request.full_url == "https://example.com/scores"
    assert timeout == 5
    return io.BytesIO(b'{"score": 85}')


print(fetch_json("https://example.com/scores", opener=fake_open))
```

```text
{'score': 85}
```

这里约定响应为 UTF-8 JSON，并设置小型示例的大小上限。真实接口还需要检查状态、响应头、业务结构和分页。

常见失败分成几层：

1. `HTTPError`：服务器返回 HTTP 错误状态，例如 404；它也是 `URLError` 的子类，需优先捕获。
2. `URLError`：解析地址、建立连接等环节失败。
3. 超时与解码错误：连接或读取未按预期完成，或字节无法按约定解码。
4. `JSONDecodeError`：响应不是合法 JSON。
5. 业务错误：JSON 合法，但字段缺失或值不符合要求。

一次请求的超时参数不一定代表整个业务流程的总时限。重试也不能无条件循环：读取类请求和会创建订单的请求，重试后果不同。

### 27.3 socket 与文本解析工具

`socket` 更接近网络基础：建立连接、发送和接收字节。TCP 提供字节流，**一次 `send()` 与一次 `recv()` 不保证一一对应**。协议需要自行规定消息边界，例如固定长度、长度前缀或换行分隔，并处理一次只收到部分消息的情况。

一般 HTTP 客户端从 `urllib.request` 或第三方 HTTP 库开始即可，不必先手写 HTTP 协议。HTML 可以先认识标准库 `html.parser.HTMLParser`：

```python
from html.parser import HTMLParser


class TextCollector(HTMLParser):
    def __init__(self):
        super().__init__()
        self.parts = []

    def handle_data(self, data):
        if data.strip():
            self.parts.append(data.strip())


parser = TextCollector()
parser.feed("<h1>Python</h1><p>学习记录</p>")
parser.close()
print(" / ".join(parser.parts))
```

```text
Python / 学习记录
```

这个简单收集器没有排除脚本和样式内容，也不执行 JavaScript。它适合演示解析回调；抓取网页正文需要更完整的规则。

**练习**：给 `fetch_json()` 增加业务校验，要求返回字典、包含数值 `score`，使用模拟响应验证正常与异常情况。

**掌握标志**：能说明“网络成功”“JSON 解析成功”“数据可用于业务”是三个不同的判断。

## 28｜系统与子进程

### 28.1 环境、解释器与路径

`os.environ` 读取进程环境变量，值都是字符串；`sys.executable` 给出当前解释器路径；`pathlib` 处理路径。相对路径通常相对于当前工作目录，不一定是脚本所在目录。

```python
import os
import sys
from unittest.mock import patch

with patch.dict(os.environ, {"REPORT_THRESHOLD": "75"}):
    threshold = int(os.environ.get("REPORT_THRESHOLD", "60"))
    print(threshold)
print(bool(sys.executable))
```

```text
75
True
```

环境变量可能不存在，也可能内容非法。读取后做类型转换和范围校验。单独设置 `env={...}` 给子进程时会替换继承环境；要保留原环境，可以使用 `{**os.environ, "KEY": "value"}`。

### 28.2 运行外部命令

```python
import subprocess
import sys

completed = subprocess.run(
    [sys.executable, "-c", "print(6 * 7)"],
    check=True,
    capture_output=True,
    text=True,
    encoding="utf-8",
    timeout=5,
)
print(completed.stdout.strip())
print(completed.returncode)
```

```text
42
0
```

参数按列表传入，一个元素对应一个参数，不需要自己拼接 shell 引号。默认不通过 shell 执行；`check=True` 将非零退出码转成异常；`capture_output=True` 收集标准输出与标准错误；`timeout` 限制等待时间。

```python
import subprocess
import sys

try:
    subprocess.run(
        [sys.executable, "-c", "raise SystemExit(2)"],
        check=True,
        capture_output=True,
        text=True,
        timeout=5,
    )
except subprocess.CalledProcessError as exc:
    print("退出码:", exc.returncode)
```

```text
退出码: 2
```

还要区别命令不存在的 `FileNotFoundError` 和超时的 `TimeoutExpired`。`check=True` 只检查退出码，不会理解输出内容是否正确。

大输出不宜全部留在内存，可以将输出重定向到文件。需要持续与子进程交互才进一步学 `Popen`、管道和进程生命周期；管道读写不当可能互相等待。

**练习**：用当前解释器运行一个独立脚本，分别处理成功、非零退出码和超时；错误信息中保留命令与必要的标准错误。

**掌握标志**：能解释当前工作目录、脚本路径、解释器路径之间的区别，并正确传递命令参数。

## 29｜测试与性能

### 29.1 测试验证行为与边界

```python
import io
import unittest


def mean_score(scores):
    valid = [score for score in scores if score is not None]
    return sum(valid) / len(valid) if valid else None


class MeanScoreTests(unittest.TestCase):
    def test_regular(self):
        self.assertEqual(mean_score([85, None, 58, 92, 0]), 58.75)

    def test_missing(self):
        self.assertIsNone(mean_score([None]))

    def test_zero(self):
        self.assertEqual(mean_score([0]), 0)


suite = unittest.defaultTestLoader.loadTestsFromTestCase(MeanScoreTests)
result = unittest.TextTestRunner(stream=io.StringIO()).run(suite)
print(result.testsRun)
print(result.wasSuccessful())
```

```text
3
True
```

这里约定调用者已验证数值类型。测试重点覆盖“零分不能丢”“没有有效值不能除零”等行为，而不是照抄函数内部实现。

生产输入校验不要依赖 `assert`：Python 的优化模式可能移除断言。测试工具中的断言用于表达预期；业务校验应显式抛出异常。

### 29.2 用替身隔离不稳定边界

```python
from unittest.mock import Mock


def load_score(fetch):
    return fetch("score/1")["score"]


fetch = Mock(return_value={"score": 85})
print(load_score(fetch))
fetch.assert_called_once_with("score/1")

fetch.side_effect = TimeoutError("请求超时")
try:
    load_score(fetch)
except TimeoutError:
    print("超时已向调用方传播")
```

```text
85
超时已向调用方传播
```

函数参数注入让边界明确。如果用 `patch()` 替换模块属性，要替换被测代码实际查找该名字的位置，而不是机械地替换最初定义的位置。

### 29.3 先测量，再优化

```python
import cProfile
import timeit


def total():
    return sum(range(1000))


elapsed = timeit.timeit(total, number=100)
print(elapsed >= 0)
profiler = cProfile.Profile()
result = profiler.runcall(total)
print(result)
```

```text
True
499500
```

`timeit` 适合重复测量小段代码；`cProfile` 适合发现函数调用和累计耗时，实际分析时调用 `profiler.print_stats(sort="cumulative")`。分配内存可进一步用 `tracemalloc` 跟踪。

不要由一次运行推断性能排名。数据规模、缓存、解释器版本、磁盘与网络状态都会影响结果。优化要保留正确性测试，并比较具有代表性的输入。

**练习**：为成绩统计补空列表、全部缺失、零分和及格线边界测试；用相同输入比较两种实现，并说明测量限制。

**掌握标志**：能复现失败、隔离外部依赖，并用测量结果定位问题。

## 30｜数据库

### 30.1 SQLite：把记录保存为可查询的表

```python
import sqlite3
from contextlib import closing

with closing(sqlite3.connect(":memory:")) as connection:
    connection.row_factory = sqlite3.Row
    connection.execute(
        "CREATE TABLE scores (name TEXT NOT NULL, score REAL)"
    )
    with connection:
        connection.executemany(
            "INSERT INTO scores (name, score) VALUES (?, ?)",
            [("小林", 85), ("小周", 58), ("小陈", None)],
        )
    rows = connection.execute(
        "SELECT name, score FROM scores WHERE score >= ? ORDER BY score DESC",
        (60,),
    ).fetchall()
    print([dict(row) for row in rows])
```

```text
[{'name': '小林', 'score': 85.0}]
```

`:memory:` 是连接内部的临时数据库；传入文件路径才能持久保存。Python 的 `None` 对应 SQL 的 `NULL`，查询空值用 `IS NULL`，不是 `= NULL`。

SQL 里的 `?` 是参数占位符，数据通过第二个参数绑定；不要用 f-string 拼接输入值。单个参数必须写成 `(60,)`。表名、列名不能作为普通值绑定，动态选择列时用预先定义的允许列表。

### 30.2 事务与关闭连接是两件事

在本篇默认事务设置下，`with connection:` 成功退出时提交当前事务，异常退出时回滚。它**不会关闭连接**，所以外面再用 `closing()`。只执行 `SELECT` 也不会因为进入 `with` 就自动开启写事务。

Python 3.12 增加了更明确的 `autocommit` 控制方式；项目应该选定一种事务策略，不要混用手动 `BEGIN`、自动提交与旧的隔离级别假设。具体行为参见 [Python 3.12 sqlite3 文档](https://docs.python.org/3.12/library/sqlite3.html)。

```python
import sqlite3
from contextlib import closing

with closing(sqlite3.connect(":memory:")) as connection:
    connection.execute("CREATE TABLE tasks (id INTEGER PRIMARY KEY, name TEXT)")
    try:
        with connection:
            connection.execute("INSERT INTO tasks VALUES (?, ?)", (1, "任务A"))
            connection.execute("INSERT INTO tasks VALUES (?, ?)", (1, "重复编号"))
    except sqlite3.IntegrityError:
        print("本批写入已回滚")
    print(connection.execute("SELECT COUNT(*) FROM tasks").fetchone()[0])
```

```text
本批写入已回滚
0
```

不要在事务内部吞掉异常后继续假装成功，否则上下文管理器可能提交已执行的部分。

### 30.3 查询、约束与索引

先认识 `SELECT`、`INSERT`、`UPDATE`、`DELETE`；再学 `WHERE`、`ORDER BY`、`GROUP BY`、聚合与连接。查询需要稳定顺序时必须明确 `ORDER BY`。

`PRIMARY KEY`、`NOT NULL`、`UNIQUE`、`CHECK` 帮数据库守住数据规则。SQLite 的普通表具有较灵活的类型行为，应用层类型校验仍然必要。

索引可以加速特定查询，同时增加写入和存储成本。针对查询条件创建索引，并用 `EXPLAIN QUERY PLAN` 观察计划；不要给每一列都加索引。SQLite 适合本地持久化和适当规模的应用，写入并发很高时需要重新评估架构。

### 30.4 综合练习：CSV → 校验 → SQLite → Markdown

下面的程序将五条测评记录保存到临时数据库，再生成报告。临时目录退出后自动清理；实际项目可将路径改为配置值。

```python
import csv
import io
import math
import sqlite3
from contextlib import closing
from pathlib import Path
from tempfile import TemporaryDirectory


def parse_records(text):
    reader = csv.DictReader(io.StringIO(text))
    if reader.fieldnames != ["name", "score"]:
        raise ValueError("CSV 表头必须为 name,score")
    records = []
    for line_number, row in enumerate(reader, start=2):
        if None in row or row["name"] is None or row["score"] is None:
            raise ValueError(f"第 {line_number} 行列数错误")
        name = row["name"].strip()
        if not name:
            raise ValueError(f"第 {line_number} 行姓名为空")
        raw_score = row["score"].strip()
        score = float(raw_score) if raw_score else None
        if score is not None and (not math.isfinite(score) or not 0 <= score <= 100):
            raise ValueError(f"第 {line_number} 行分数越界")
        records.append((name, score))
    return records


def make_report(connection):
    total, valid, average, passed = connection.execute(
        "SELECT COUNT(*), COUNT(score), AVG(score), "
        "COALESCE(SUM(CASE WHEN score >= ? THEN 1 ELSE 0 END), 0) FROM scores",
        (60,),
    ).fetchone()
    mean_text = f"{average:.2f}" if average is not None else "暂无数据"
    return (
        "# 测评报告\n\n"
        f"- 总人数：{total}\n- 有效成绩：{valid}\n"
        f"- 缺失成绩：{total - valid}\n- 及格人数：{passed}\n"
        f"- 平均分：{mean_text}\n"
    )


source = "name,score\n小林,85\n小周,58\n小陈,92\n小吴,0\n小李,\n"
records = parse_records(source)
with TemporaryDirectory() as directory:
    root = Path(directory)
    with closing(sqlite3.connect(root / "scores.db")) as connection:
        connection.execute(
            "CREATE TABLE scores (id INTEGER PRIMARY KEY, name TEXT NOT NULL, "
            "score REAL CHECK (score IS NULL OR score BETWEEN 0 AND 100))"
        )
        with connection:
            connection.executemany(
                "INSERT INTO scores (name, score) VALUES (?, ?)", records
            )
        report = make_report(connection)
    output = root / "report.md"
    output.write_text(report, encoding="utf-8")
    print(output.read_text(encoding="utf-8"), end="")
```

```text
- 有效成绩：4
- 缺失成绩：1
- 及格人数：2
- 平均分：58.75
```

`COUNT(*)` 数行，`COUNT(score)` 只数非空分数，`AVG(score)` 忽略 `NULL`、保留零分。空输入时平均值是 `NULL`，报告应显示“暂无数据”。记录用独立编号标识，没有假设姓名唯一。

这个练习一次性读取所有 CSV 记录，适合小文件；大文件需要流式读取与分批事务。重复导入会新增记录，真实系统需要定义导入批次或去重规则。数据库提交和报告文件写入也不是同一个原子操作；报告失败可以由已保存的数据重新生成。
