# Python 语言地基：从运行程序到组织函数

本篇对应 [Python 全景地图](./0-全景地图.md) 的 **L1**，按蛇形图的 **1–6** 顺序学习：环境与运行、变量与类型、字符串、容器与数据结构、表达式与控制流、函数基础。

**学习目标**：能独立写一个短脚本，完成输入、处理和输出；能选用合适的容器；能区分重新赋值与修改对象；能把重复逻辑封装成函数。

示例面向 Python **3.10 及以上版本**，其中 `match` 需要 Python 3.10+。终端命令统一写 `python`，如果你的电脑使用 `python3`，请相应替换。代码框标为 `python` 的内容放进 Python 执行，标为 `bash` 的命令在终端执行，`text` 框展示结果。

各个 Python 示例可以独立运行。标明需要键盘输入的示例，请按提示输入。路径、版本号、错误行号等随运行环境变化。

学习时先运行示例，再改一个值观察结果，最后完成小练习。贯穿全文的场景是：保存测评分数、筛选及格记录、计算平均分、输出报告。文件读写、异常捕获、类和包的系统讲解留到 [2-程序骨架](./2-程序骨架.md)。

## 1｜环境与运行

**这一节解决的问题**：代码在哪里写，由谁执行，怎样用虚拟环境隔离依赖，怎样运行，出错后从哪里看起？

### 1.1 解释器、编辑器与脚本

写 Python 离不开三样东西，分工不同：

| 角色 | 做什么 | 常见形态 |
|------|--------|----------|
| **编辑器** | 编写、保存、查看代码 | VS Code、Cursor、PyCharm、记事本 |
| **解释器** | 真正执行代码 | 终端里的 `python` / `python3` 命令 |
| **脚本** | 存放代码的文件 | 以 `.py` 结尾的文本文件 |

**编辑器**负责「写」。它帮你改文字、高亮语法、提示括号是否配对；带调试、项目管理功能的叫 **IDE**（集成开发环境），本质仍是编辑器的加强版。代码写完只是落在磁盘上的文本，编辑器本身**不会**替你跑程序。

**解释器**负责「跑」。终端里敲 `python hello.py` 时，真正干活的是解释器：它读取 `.py` 文件，按语法解析，再一行行执行。日常说的「安装 Python」，主要就是安装解释器（常见发行版是 CPython）。没有解释器，再漂亮的代码也跑不起来。

**脚本**就是那份 `.py` 文件，把可复用的代码保存下来，方便反复执行。把代码写进编辑器，**不等于**已经运行——必须通过解释器启动一次，结果才会出现在终端。

三者的关系可以记成：**编辑器写脚本 → 解释器读脚本并执行 → 终端显示输出**。

先在终端确认解释器是否可用：

```bash
python --version
python -c "import sys; print(sys.executable)"
```

第一条显示版本，第二条显示本次调用的解释器路径。安装了多个 Python 时，这能帮助你确认自己到底在用哪一个。若命令报 `command not found`，说明当前终端找不到解释器，需要先安装或检查 PATH。

`sys` 是 Python 的标准库模块，提供解释器相关信息。此处先认识“`import sys` 把模块引入程序”，导入机制以后再深入。

### 1.2 虚拟环境与 conda

**虚拟环境**是给单个项目准备的「独立小 Python」：自带一份解释器入口和一套已安装的第三方包，与系统全局 Python、以及其他项目互不混用。

为什么需要它？机器上往往有多个项目。项目 A 要 `requests==2.28`，项目 B 要 `requests==2.32`；若都装进同一个全局环境，版本会互相踩脚，出现「这个项目能跑、那个项目 import 报错」的情况。虚拟环境把依赖关进各自的目录里，换项目就换环境。

使用虚拟环境的常见好处：

- **隔离依赖**：每个项目只看见自己装过的包，避免版本冲突。
- **可复现**：配合依赖清单，别人或另一台电脑能重建相近环境。
- **不污染系统**：练习、试装包不会弄乱系统自带的 Python。
- **切换干净**：用完可删除整个环境目录，比从全局里卸载包更省事。

入门阶段最常见的两种工具：

| 工具 | 是什么 | 适合什么时候用 |
|------|--------|----------------|
| **`venv`** | Python 标准库自带的虚拟环境工具 | 一般开发、学习、Web / 脚本项目；优先掌握 |
| **conda** | 包与环境管理器（常随 Anaconda / Miniconda 安装） | 数据科学、需要特定 Python 版本或大量非 Python 依赖时 |

**用 `venv` 创建并启用**（在项目目录执行）：

```bash
python -m venv .venv
```

macOS / Linux 激活：

```bash
source .venv/bin/activate
```

Windows PowerShell 激活：

```powershell
.\.venv\Scripts\Activate.ps1
```

激活成功后，终端提示符前常出现 `(.venv)`；此时的 `python` 和 `pip` 指向这个环境，而不是系统全局。确认一下：

```bash
python -c "import sys; print(sys.executable)"
```

路径里应出现 `.venv`。退出当前环境：

```bash
deactivate
```

**用 conda 创建并启用**（需已安装 Anaconda 或 Miniconda）：

```bash
conda create -n agent-demo python=3.11
conda activate agent-demo
python -c "import sys; print(sys.executable)"
conda deactivate
```

`conda create` 新建名为 `agent-demo` 的环境并指定 Python 版本；`conda activate` / `conda deactivate` 负责进入和退出。conda 既能管 Python 包，也能安装不少科学计算相关的非 Python 依赖，因此在数据与机器学习场景里很常见。

怎么选？日常写脚本、学语法、做后端练习，用 **`venv` 即可**；已经在用 Jupyter、NumPy/Pandas 全家桶，或团队统一用 conda，再选 conda。二者都是在「隔离环境」，不要混在同一个项目里叠床架屋。

注意几件入门易混的事：

- 虚拟环境隔离的是**包与解释器入口**，不是操作系统；网络、文件权限仍与本机相同。
- `.venv` 目录一般**不要提交到 Git**；换机器时重建环境，而不是复制整个文件夹。
- 编辑器 / IDE 里也要选对解释器（指向 `.venv` 或 conda 环境），否则会出现「终端里能 import、编辑器里报红」的错位。

第三方包的安装、`requirements.txt` 与项目配置，会在 [2-程序骨架](./2-程序骨架.md) 中系统练习；本节先建立「一项目一环境」的习惯。

### 1.3 三种运行方式

**运行脚本**适合保存和反复执行。新建 `hello.py`，写入：

```python
print("你好，Python！")
```

```text
你好，Python！
```

保存后，在该文件所在目录的终端执行：

```bash
python hello.py
```

终端的**当前工作目录**就是此时所在的文件夹。上面的相对文件名会相对于它查找；文件存在于别处时，要先切换目录或提供正确路径。

**交互环境 REPL**适合临时尝试。在终端执行 `python` 后，会看到 `>>>` 提示符。输入表达式即可查看结果；输入 `exit()` 退出。复制交互示例时，不要把 `>>>` 当成代码。

**单行命令**适合快速验证：

```bash
python -c "print(1 + 1)"
```

```text
2
```

### 1.4 print：把结果显示出来

`print()` 将内容输出到终端。多个参数默认用空格分隔，每次调用默认换行。

```python
print("姓名", "小林", "分数", 85)
print("姓名", "分数", sep=" | ")
print("正在统计", end="：")
print("完成")
```

```text
姓名 小林 分数 85
姓名 | 分数
正在统计：完成
```

REPL 可能自动显示表达式结果；脚本中的一行 `1 + 1` 不会自动打印，想看结果要写 `print(1 + 1)`。

### 1.5 input：取得键盘输入

`input()` 显示提示并等待输入，返回的内容是**字符串**。

下面需要手动输入姓名：

```python
name = input("请输入姓名：")
print("你好，", name, sep="")
```

输入“小林”并按回车后，程序输出“你好，小林”。变量保存和类型转换会在下一节展开。

### 1.6 缩进、注释与源码编码

Python 用缩进划分代码块。通常每层使用 **4 个空格**，不要混用 Tab 和空格。

```python
score = 85
if score >= 60:
    print("及格")  # 这一行属于 if 代码块
print("检查完成")  # 回到外层，无论是否及格都会执行
```

```text
及格
检查完成
```

这里的 `if` 先用于观察缩进，第 5 节会详细讲条件分支。

`#` 后的文字是注释，不参与执行。Python 3 源码默认按 UTF-8 解码，保存中文代码和注释时也应使用 UTF-8。**源码编码**与程序运行时处理的文件、网络数据编码是两个问题；后者需要根据数据来源确定。

### 1.7 怎样读基本报错

先看报错最后一行的**错误类型与描述**，再回看它指向的文件和行号。例如，在没有定义 `score` 的情况下执行 `print(score)`，通常会出现：

```text
NameError: name 'score' is not defined
```

入门时先区分这些常见情况：

- `SyntaxError`：语法写错，如括号或冒号缺失。
- `IndentationError`：代码块缩进不合法。
- `NameError`：当前找不到这个名字，可能未赋值或拼写错误。
- `TypeError`：操作与对象类型不匹配，如直接把字符串和整数相加。
- `ValueError`：类型可以接受，但具体值无法完成操作，如 `int("通过")`。

不要只改报错最后一个词。先定位行，再检查参与这行运算的值和类型。如何捕获错误、让程序继续运行，留到 L2 学习。

**本节练习**：创建一个脚本，读取姓名，再输出欢迎语；分别用脚本和单行命令打印同一句话。再在练习目录用 `venv` 建一个 `.venv`，激活后打印 `sys.executable`，确认路径指向该环境。

**过关标准**：能自己运行 `.py` 文件，分清终端命令与 Python 代码；知道虚拟环境解决什么问题，能创建并激活 `venv`；知道缩进表示什么，能从报错中定位出错行。

## 2｜变量与类型

**这一节解决的问题**：程序保存的是什么，变量如何关联数据，不同类型能做哪些操作？

### 2.1 赋值：把名字绑定到对象

可以把变量名理解为对象的标签。`name = "小林"` 表示让 `name` 指向这个字符串对象；`=` 是赋值，不是判断相等。

```python
name = "小林"
score = 85
average_score = 82.5
passed = True
comment = None

print(name, score, average_score, passed, comment)
```

```text
小林 85 82.5 True None
```

变量名应表达含义，例如 `score`、`case_count`。名称可以包含字母、数字、下划线，但不能以数字开头，也不能使用 `if`、`for` 等关键字；大小写有区别。

不要把变量命名为 `list`、`str`、`sum` 等常用内置名称，否则会遮住同名功能，导致后面的调用难以理解。

### 2.2 动态类型、type、isinstance 与 id

类型属于对象。一个变量可以先关联整数，随后关联字符串；这不表示原来的整数对象变成了字符串。

```python
value = 85
print(type(value).__name__)
value = "85"
print(type(value).__name__)
print(isinstance(value, str))
```

```text
int
str
True
```

- `type(value)`：查看对象的具体类型。
- `isinstance(value, str)`：判断是否属于指定类型或其子类。
- `id(value)`：取得对象的身份标识；在对象存活期间保持不变。不要把具体编号写死，也不要用它代替业务数据的比较。

### 2.3 数字、布尔值和空值

**整数 `int`**适合计数，**浮点数 `float`**适合表示近似小数，**布尔值 `bool`**表示 `True` 或 `False`。`None` 是一个特殊对象，常用于表达“尚无结果”或“缺失”。

```python
count = 3
score = 85.5
passed = score >= 60
missing = None

print(type(count).__name__)
print(type(score).__name__)
print(passed)
print(missing is None)
```

```text
int
float
True
True
```

`None`、数字 `0`、空字符串 `""` 的含义不同。例如，分数 `0` 是有效的测评结果，`None` 可以表示还没测评；不要把两者当成同一件事。

了解即可：Python 也有复数 `complex`，例如 `2 + 3j`。普通测评脚本通常不需要它。

### 2.4 类型转换

从键盘读取的数字文本，需要转换后才能进行数值计算：

```python
raw_score = "85"
score = int(raw_score)
print(score + 5)
print(float("85.5"))
print(str(85) + " 分")
print(int(85.9))
```

```text
90
85.5
85 分
85
```

`int(85.9)` 向零截断，不是四舍五入。`int("85.5")` 也不能直接处理带小数点的字符串，需要先明确你要保留小数还是转换为整数。

`int("通过")` 会报错。类型转换不会自动修复任意输入；处理用户输入错误属于后续异常处理内容。

### 2.5 真值测试

在条件判断中，Python 可以把对象按“真或假”来判断。常见假值包括 `False`、`None`、数值零、空字符串和空容器。

```python
print(bool(0), bool(1))
print(bool(""), bool("False"))
print(bool(None))
```

```text
False True
False True
False
```

**`bool("False")` 是 `True`**，因为它是非空字符串。`bool()` 不会把英文单词当作配置值来解释。

如果你要判断“是不是缺失”，用 `value is None`；如果你要判断“是不是非空”，才考虑真值测试。

### 2.6 可变、不可变，以及重新赋值

整数、浮点数、布尔值和字符串是不可变对象：不能在原对象上修改它的值。列表、字典和集合是可变对象：内容可以被原地修改。

先观察整数：

```python
a = 85
b = a
a = 90
print(a, b)
```

```text
90 85
```

`a = 90` 让 `a` 关联另一个值，不会把 `b` 也改成 90。

再观察列表。这里先把方括号理解为“一组值”，完整操作在第 4 节讲解：

```python
a = [85, 60]
b = a
print(id(a) == id(b))
a.append(90)
print(b)
a = [100]
print(a, b)
```

```text
True
[85, 60, 90]
[100] [85, 60, 90]
```

`b = a` 没有复制列表。开始时两个名字指向同一对象，`append()` 修改了共享的列表；之后 `a = [100]` 是重新绑定，只改变 `a` 的指向。浅拷贝、深拷贝的系统讨论留到 L2。

### 2.7 浮点精度与数值工具

很多十进制小数无法用有限位二进制精确表示：

```python
import math

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3))
```

```text
0.30000000000000004
False
True
```

`math.isclose()` 用容差判断数值是否接近，容差应根据业务确定；比较接近零的数值时，也要考虑设置合适的绝对容差。显示时保留两位小数，不等于修改了底层数值的表示方式。

作为加餐，认识三个标准库：`math` 提供数学函数，`decimal` 提供十进制运算，`fractions` 提供分数运算。

```python
from decimal import Decimal
from fractions import Fraction

print(Decimal("0.1") + Decimal("0.2"))
print(Fraction(1, 3) + Fraction(1, 6))
```

```text
0.3
1/2
```

这里用字符串构造 `Decimal`，避免先引入浮点近似误差。

**本节练习**：把字符串分数 `"88.5"` 转为数值并增加 1 分；解释为什么 `bool("0")` 为真，以及 `None` 和零分为何不同。

**过关标准**：能用 `type` 检查类型，能完成基本转换，能解释共享列表与重新赋值的区别。

## 3｜字符串

**这一节解决的问题**：怎样取出、清洗、组合和展示文本，以及文本与字节有什么区别？

### 3.1 索引与切片

字符串是不可变的文本序列。索引从 `0` 开始，负索引从末尾计数；切片写成 `[开始:结束:步长]`，**包含开始，不包含结束**。

```python
text = "Python"
print(text[0])
print(text[-1])
print(text[0:3])
print(text[::2])
print(text[::-1])
```

```text
P
n
Pyt
Pto
nohtyP
```

单个索引越界会报 `IndexError`；普通切片超出边界时会截取实际存在的部分。空字符串没有第一个字符，不能直接取 `[0]`。

### 3.2 清洗、查找与替换

```python
raw = "  Python 入门  "
clean = raw.strip()
print(clean)
print(clean.replace("入门", "基础"))
print("Python" in clean)
print(clean.find("入门"))
print(clean.find("Java"))
print("Agent".lower())
```

```text
Python 入门
Python 基础
True
7
-1
agent
```

`strip()` 默认去掉两端空白，不会去掉中间的空格。`find()` 返回首次出现的位置，找不到时返回 `-1`；不要直接写 `if text.find(...)` 来判断是否找到，因为位置 `0` 会被当成假值。

简单的包含判断使用 `in`；文本清洗常用 `strip()`、`lower()`、`replace()`。是否忽略大小写或空格，要根据业务规则决定。

### 3.3 字符串不可变

```python
text = "python"
upper_text = text.upper()
print(text)
print(upper_text)
```

```text
python
PYTHON
```

方法返回处理后的字符串，原字符串没有被修改。`text[0] = "P"` 不合法；需要保留处理结果时，重新赋值即可：`text = text.upper()`。

### 3.4 分割与拼接

`split()` 把字符串拆成列表，`join()` 把一组字符串连接起来。列表的更多操作放在下一节。

```python
raw = "小林,85,及格"
parts = raw.split(",")
print(parts)
print(" / ".join(parts))
print("  小林   85  ".split())
```

```text
['小林', '85', '及格']
小林 / 85 / 及格
['小林', '85']
```

`split()` 不传参数时按空白分割，并处理连续空白。`join()` 的元素需要是字符串；混入整数时，应先明确如何转成文本。

### 3.5 f-string：让变量进入输出文本

```python
name = "小林"
score = 85.678
pass_rate = 0.75

print(f"{name}：{score:.2f} 分")
print(f"及格率：{pass_rate:.0%}")
print(f"下次目标：{score + 2:.2f} 分")
```

```text
小林：85.68 分
及格率：75%
下次目标：87.68 分
```

字符串前的 `f` 表示格式化字符串，花括号里可以写变量或表达式。`:.2f` 表示显示两位小数，`:.0%` 表示转成百分比显示且不保留小数。

显示格式不会改变 `score` 原来的数值。只需要展示文本时，用格式化即可，不必先把分数改成字符串存回原数据。

### 3.6 str 与 bytes：编码和解码

`str` 表示 Unicode 文本，`bytes` 表示字节序列。**编码**把文本变成字节，**解码**把字节变回文本。

```python
text = "中文"
data = text.encode("utf-8")

print(type(text).__name__, type(data).__name__)
print(len(text), len(data))
print(data.decode("utf-8"))
```

```text
str bytes
2 6
中文
```

这个例子中两个汉字的 UTF-8 编码共占 6 个字节；不要推断所有字符都占同样字节数。`len(str)` 计算 Unicode 码位数量，也不一定等于屏幕上看到的字符块数量，例如某些组合字符和 emoji。

解码时应使用数据实际采用的编码。编码不匹配可能报错，也可能产生乱码，不能靠随意换编码来保证内容正确。

**本节练习**：把 `"  小林,88.5  "` 去掉两端空白，分割姓名和分数，再输出“小林：88.50 分”。

**过关标准**：能进行切片和文本清洗，知道字符串方法不会原地修改对象，能解释 `str` 与 `bytes` 的区别。

## 4｜容器与数据结构

**这一节解决的问题**：一组值、一条记录、重复标签，分别用什么存？

### 4.1 列表 list：有顺序、可修改的一组数据

列表适合保存一批分数或记录，允许重复，按索引访问。

```python
scores = [85, 60, 92]
scores.append(75)
scores[1] = 65
print(scores[0])
print(scores[1:3])
print(scores.pop())
print(scores)
```

```text
85
[65, 92]
75
[85, 65, 92]
```

常见操作还包括：`insert()` 插入、`extend()` 追加一批元素、`remove()` 删除第一个相等的元素、`del scores[index]` 按位置删除。`remove()` 按值删，`pop()` 按位置移除并返回元素。

`append()` 是原地操作，返回 `None`。不要写 `scores = scores.append(90)`，这会把变量变成 `None`。

### 4.2 排序：返回新列表还是修改原列表

```python
scores = [85, 60, 92]
ordered = sorted(scores)
print(scores)
print(ordered)
scores.sort(reverse=True)
print(scores)
```

```text
[85, 60, 92]
[60, 85, 92]
[92, 85, 60]
```

`sorted()` 返回新列表；列表的 `.sort()` 原地排序并返回 `None`。需要保留原始顺序时，优先考虑返回新列表的方式。

### 4.3 元组 tuple：固定的一组位置

元组常用于表达一组固定位置的数据。单元素元组需要逗号，`(85)` 只是带括号的整数。

```python
record = ("小林", 85)
name, score = record
single = (85,)
print(name, score)
print(type(single).__name__)
```

```text
小林 85
tuple
```

元组不可变，指的是不能替换、增加或删除它的元素位置；**元组内部引用的可变对象仍然可能变化**：

```python
record = ("小林", [85, 90])
record[1].append(95)
print(record)
```

```text
('小林', [85, 90, 95])
```

### 4.4 字典 dict：用名字查值

字典适合表达一条记录、配置或映射。键不能重复；给已有键赋值会更新该键的值。

```python
record = {"name": "小林", "score": 85}
print(record["name"])
print(record.get("comment", "暂无评语"))
record["score"] = 90
record["passed"] = True
print(record)
```

```text
小林
暂无评语
{'name': '小林', 'score': 90, 'passed': True}
```

`record["缺失的键"]` 会报 `KeyError`；`get()` 可以提供缺失时的默认值，但默认值不会自动写进字典。`"score" in record` 判断的是键是否存在。

字典保留插入顺序，但它仍然按键访问，不能把 `record[0]` 理解为“第一条记录”，除非它真的有整数键 `0`。

### 4.5 可哈希：什么可以当字典键和集合元素

字典键、集合元素需要是**可哈希对象**。常见可用对象包括字符串、整数，以及元素都可哈希的元组；列表、字典和普通集合不可以。

```python
scores = {("小林", "第一轮"): 85}
print(scores[("小林", "第一轮")])
```

```text
85
```

不要简单理解成“所有元组都可以当键”：包含列表的元组就不行。此处先记住常用类型的规则，`__hash__` 与相等比较的关系留到语言内核部分学习。

### 4.6 集合 set 与 frozenset：去重和关系运算

集合适合去重、成员判断、交并差运算，不提供按索引取值的接口，也不保证按插入顺序输出。

```python
a = {"基础", "函数", "基础"}
b = {"函数", "容器"}
print(sorted(a))
print(sorted(a & b))
print(sorted(a | b))
print(sorted(a - b))
print(sorted(a ^ b))
```

```text
['函数', '基础']
['函数']
['函数', '基础', '容器']
['基础']
['基础', '容器']
```

这里用 `sorted()` 让展示结果稳定。`&` 表示交集，`|` 表示并集，`-` 表示差集，`^` 表示对称差集。

普通集合可以用 `add()` 添加、`discard()` 删除；`discard()` 在元素不存在时也不会报错。空集合写 `set()`，`{}` 是空字典。

`frozenset` 是不可变集合，可以作为字典键或另一个集合的元素：

```python
labels = frozenset(["基础", "函数"])
print("基础" in labels)
print(type(labels).__name__)
```

```text
True
frozenset
```

### 4.7 嵌套、解包与遍历入口

用“列表装多条记录、字典装一条记录”表达测评数据：

```python
records = [
    {"name": "小林", "score": 85},
    {"name": "小周", "score": 58},
]
print(records[0]["name"])
print(records[1]["score"])

first, *middle, last = [60, 70, 80, 90]
print(first, middle, last)
```

```text
小林
58
60 [70, 80] 90
```

`records[0]["name"]` 先取第一条记录，再取它的姓名。赋值解包可以拆出多个元素，带星号的位置收集剩余元素；不带星号时，变量数量与元素数量要匹配。

字典提供 `.keys()`、`.values()`、`.items()`，分别用于访问键、值、键值对。容器通常配合 `for` 遍历，下一节会把它们连起来使用。

### 4.8 按需求选择容器

- 保存按顺序处理的一批用例：用 `list`。
- 打包固定位置的数据，例如坐标或姓名与分数：可以用 `tuple`。
- 保存有字段名的记录，例如 `name`、`score`：用 `dict`。
- 标签去重、判断共同标签：用 `set`。
- 需要不可变的标签集合或集合作为键：考虑 `frozenset`。

**本节练习**：创建三条姓名与分数记录，放进列表；修改其中一个分数；用集合去重重复的课程标签。说明这些操作为什么选择对应容器。

**过关标准**：能独立完成容器增删改查，能区分 `.sort()` 与 `sorted()`，能解释为什么赋值不会自动复制容器。

## 5｜表达式与控制流

**这一节解决的问题**：怎样计算、判断、重复执行，以及何时结束？

### 5.1 算术、比较与成员判断

```python
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 3)
print(-7 // 2)
print(60 <= 85 <= 100)
print("函数" in ["基础", "函数"])
```

```text
3.5
3
1
8
-4
True
True
```

`/` 是除法，`//` 是向下取整的除法，`%` 取余，`**` 是乘方。尤其要注意负数：`-7 // 2` 是 `-4`，不能把 `//` 当成向零截断。

比较运算有 `==`、`!=`、`<`、`<=`、`>`、`>=`。`in` 和 `not in` 做成员判断，字典默认检查键。复杂表达式可加括号，把分组写清楚。

### 5.2 == 比较值，is 比较身份

```python
a = [85, 60]
b = [85, 60]
c = a

print(a == b)
print(a is b)
print(a is c)
```

```text
True
False
True
```

两个列表的内容相等，但可以是不同对象。判断数值或字符串是否相等使用 `==`；判断是否为 `None` 使用 `is None`。

不要依赖小整数缓存或字符串驻留来写 `is` 比较，即使某一次运行恰好得到 `True`，也不代表它表达了你要的业务条件。

### 5.3 布尔运算与短路求值

`and` 在左侧为假时不再计算右侧，`or` 在左侧为真时不再计算右侧，`not` 对真值取反。

```python
count = 0
print(count != 0 and 100 / count > 10)
print("" or "匿名")
print("小林" or "匿名")
print(not [])
```

```text
False
匿名
小林
True
```

第一行利用短路，避免在 `count` 为零时执行除法。`and`、`or` 返回选中的操作数，不一定返回布尔值。

`value or default` 会把零、空字符串等所有假值都替换掉。如果只想替换缺失值，应明确判断 `None`：

```python
score = 0
shown = "未测评" if score is None else score
print(shown)
```

```text
0
```

### 5.4 if / elif / else：按条件选择分支

```python
score = 85

if score >= 90:
    grade = "优秀"
elif score >= 60:
    grade = "及格"
else:
    grade = "未及格"

print(grade)
```

```text
及格
```

条件从上到下检查，一旦命中某个分支，就跳过后面的 `elif` 和 `else`。把 `score >= 60` 写在 `score >= 90` 前面，会让高分提前进入“及格”分支。

如果要分别执行多个独立检查，可以写多个 `if`，而不是把它们连成互斥的 `elif`。

### 5.5 match：按模式匹配

`match` 可以根据值的形式进行匹配；入门先用字符串常量理解它：

```python
status = "done"

match status:
    case "pending":
        message = "等待处理"
    case "done":
        message = "处理完成"
    case _:
        message = "未知状态"

print(message)
```

```text
处理完成
```

`case _` 是兜底分支。字符串常量要写引号；裸名字可能表示捕获变量，不要把 `case done:` 当成字符串比较。结构化匹配可后续再深入，简单数值范围判断先用 `if` 即可。

### 5.6 for：遍历容器

```python
records = [
    {"name": "小林", "score": 85},
    {"name": "小周", "score": 58},
]

for record in records:
    print(record["name"], record["score"])

for key, value in records[0].items():
    print(key, value)
```

```text
小林 85
小周 58
name 小林
score 85
```

第一段遍历列表元素，第二段遍历字典键值对。尽量不要在遍历同一个容器时增删它的元素；筛选数据时，可以新建一个列表保存结果。

`range()` 生成整数范围，结束值不包含在内；`enumerate()` 同时提供序号和元素，`zip()` 把多组数据配对：

```python
print(list(range(1, 4)))

for index, name in enumerate(["小林", "小周"], start=1):
    print(index, name)

for name, score in zip(["小林", "小周"], [85, 58]):
    print(name, score)
```

```text
[1, 2, 3]
1 小林
2 小周
小林 85
小周 58
```

`zip()` 默认在最短输入耗尽时停止。若要求两边长度相同，可以先检查长度，或使用 `zip(..., strict=True)`，长度不一致时它会报错。

### 5.7 while、break 与 continue

`while` 在条件为真时重复执行。要确保某一步能让条件变假，或能通过 `break` 结束。

```python
remaining = 3
while remaining > 0:
    print(remaining)
    remaining -= 1
print("开始")
```

```text
3
2
1
开始
```

`continue` 跳过当前这一轮剩余代码，`break` 结束当前这一层循环：

```python
for score in [None, 58, 85, 92]:
    if score is None:
        continue
    if score >= 60:
        print("第一个及格分数：", score, sep="")
        break
```

```text
第一个及格分数：85
```

不要用 `if not score` 排除缺失值，否则零分也会被跳过。多层嵌套时，`break` 只退出它所在的最内层循环。

### 5.8 循环 else：没有 break 时执行

`for` 和 `while` 都可以带 `else`。它不是“条件不成立时对应的普通分支”，而是表示循环正常结束、没有通过 `break` 提前退出时执行。

```python
for score in [45, 58]:
    if score >= 60:
        print("找到及格记录")
        break
else:
    print("没有找到及格记录")
```

```text
没有找到及格记录
```

这个结构适合“搜索，找到了就退出，没找到就报告”的任务。空列表也会执行 `else`；抛出异常或通过函数 `return` 离开，不属于这里的正常结束。

### 5.9 常用统计与反向遍历

```python
scores = [85, 58, 92]
print(sum(scores))
print(min(scores), max(scores))
print(list(reversed(scores)))
print(any([False, True, False]))
print(all([True, True, False]))
print(any([]), all([]))
```

```text
235
58 92
[92, 58, 85]
True
False
False True
```

`any()` 判断是否至少有一个真值，`all()` 判断是否全部为真值。空输入时 `any([])` 为假，`all([])` 为真。

`sum([])` 为零，但空列表直接调用 `min()`、`max()` 会报错；计算平均分之前，也必须考虑数量为零的情况。

### 5.10 了解：位运算与赋值表达式

对整数，`&`、`|`、`^` 是按位与、或、异或，`<<` 和 `>>` 是移位；它们与布尔逻辑 `and`、`or` 不同。相同符号用于集合时，则有集合运算的含义。

```python
print(6 & 3)
print(6 | 3)
print(6 ^ 3)
print(1 << 3)
print(8 >> 1)
```

```text
2
7
5
8
4
```

赋值表达式 `:=` 允许在表达式内绑定一个值。例如既要使用长度判断，又要输出长度：

```python
scores = [85, 58, 92]
if (count := len(scores)) > 0:
    print(f"共有 {count} 条记录")
```

```text
共有 3 条记录
```

初学时分成 `count = len(scores)` 和 `if count > 0:` 两句同样清楚，不需要为了简短而强行使用 `:=`。

**本节练习**：从 `[85, None, 58, 92, 0]` 中跳过缺失值，保留零分，收集及格成绩，并输出有效记录数量与平均分。

**过关标准**：能说明执行哪个分支、循环何时结束，能正确使用 `break` 和 `continue`，能处理空数据与缺失数据。

## 6｜函数基础

**这一节解决的问题**：如何给一段逻辑命名、传入数据、返回结果，并在不同地方复用？

### 6.1 定义、调用与返回

`def` 定义函数，括号里写参数，函数体通过缩进划分。定义时不会立即执行函数体，调用时才执行。

```python
def is_passed(score):
    return score >= 60

print(is_passed(85))
print(is_passed(58))
```

```text
True
False
```

这里 `score` 是函数定义中的参数，`85` 是调用时传入的值。函数拿到数据后进行判断，再把结果返回给调用方。

### 6.2 return 与 print 的区别

`print()` 把结果显示出来，`return` 把值交还调用方并结束本次函数执行。函数执行到末尾没有 `return`，或者只写不带值的 `return`，返回值都是 `None`。

```python
def show_score(score):
    print(f"分数：{score}")

def format_score(score):
    return f"分数：{score}"

result = show_score(85)
print(result)
print(format_score(85))
```

```text
分数：85
None
分数：85
```

如果后面还要统计、保存或拼接结果，通常应返回数据；如果函数本身就是展示报告，则可以负责打印。不要把“终端里看到了”误认为“函数已经返回了这个结果”。

### 6.3 位置参数、关键字参数与默认参数

```python
def is_passed(score, threshold=60):
    return score >= threshold

print(is_passed(75))
print(is_passed(75, 80))
print(is_passed(score=75, threshold=70))
```

```text
True
False
True
```

位置参数按位置匹配，关键字参数按名称匹配，省略可选参数时使用默认值。普通调用中位置参数放在关键字参数前面；同一个参数不能被重复赋值。

如果某个选项必须显式写名字，可以放在单独的 `*` 后面：

```python
def is_passed(score, *, threshold=60):
    return score >= threshold

print(is_passed(75, threshold=80))
```

```text
False
```

这里不能写 `is_passed(75, 80)`，因为 `threshold` 是仅限关键字参数。

### 6.4 *args、**kwargs 与调用解包

定义函数时，`*args` 收集额外的位置参数，得到元组；`**kwargs` 收集额外的关键字参数，得到字典。`args` 和 `kwargs` 是常用命名，起作用的是前面的星号。

```python
def describe_scores(*scores, **options):
    print(scores)
    print(options)

describe_scores(85, 58, title="第一轮", threshold=60)
```

```text
(85, 58)
{'title': '第一轮', 'threshold': 60}
```

调用时含义相反：`*` 把序列展开为位置参数，`**` 把映射展开为关键字参数。

```python
def make_record(name, score, *, group="默认组"):
    return {"name": name, "score": score, "group": group}

values = ["小林", 85]
options = {"group": "第一组"}
print(make_record(*values, **options))
```

```text
{'name': '小林', 'score': 85, 'group': '第一组'}
```

`**` 展开的关键字名称必须是字符串，且要符合函数能接收的参数；重复传入同名参数也会报错。

### 6.5 默认参数陷阱

默认参数在**执行函数定义时**求值，不是每次调用都重新创建。下面的写法会共享同一个列表：

```python
def bad_add(name, names=[]):
    names.append(name)
    return names

print(bad_add("小林"))
print(bad_add("小周"))
```

```text
['小林']
['小林', '小周']
```

第二次调用带上了第一次的内容。如果想在未传列表时每次创建新的容器，可以这样写：

```python
def add_name(name, names=None):
    if names is None:
        names = []
    names.append(name)
    return names

print(add_name("小林"))
print(add_name("小周"))
```

```text
['小林']
['小周']
```

如果调用方主动传入一个列表，该函数仍然会修改这个列表。是否修改传入数据，应在函数设计时说清楚。

### 6.6 lambda 与 callable

`lambda` 创建一个只有单个表达式的匿名函数，适合排序取值等短逻辑。复杂逻辑使用有名字的 `def` 更容易阅读。

```python
records = [
    {"name": "小林", "score": 85},
    {"name": "小周", "score": 58},
    {"name": "小陈", "score": 92},
]
ordered = sorted(records, key=lambda record: record["score"], reverse=True)
print(ordered[0]["name"])
print(callable(lambda score: score >= 60))
print(callable(85))
```

```text
小陈
True
False
```

这里 `key` 接收一个函数，排序时从每条记录取出分数。`callable()` 判断对象是否可调用，但不能保证你用任意参数调用它都成功。

### 6.7 初识 map 与 filter

先理解函数如何接收参数和返回结果，再认识“把函数作为参数”的工具：

```python
def is_passed(score):
    return score >= 60

scores = list(map(float, ["85", "58", "92"]))
passed = list(filter(is_passed, scores))
print(scores)
print(passed)
```

```text
[85.0, 58.0, 92.0]
[85.0, 92.0]
```

`map()` 对元素应用函数，`filter()` 根据函数返回值的真假筛选元素。Python 3 中它们返回迭代器，这里用 `list()` 收集结果以便显示。先用普通循环写清逻辑也完全可以，迭代器和高阶函数在 L3 再系统学习。

### 6.8 综合练习：测评成绩汇总

现在把六个节点串起来：

- 用变量保存及格线。
- 用列表保存多条记录，用字典保存姓名和分数。
- 用条件跳过缺失分数，保留零分。
- 用循环筛选及格记录、统计平均分。
- 用函数拆开筛选、统计与输出，用 f-string 展示结果。

**输入约定**：每条记录都包含 `name` 和 `score`；姓名为字符串，分数为 0–100 的数值或 `None`。此处使用受控示例数据；外部数据的格式校验和异常处理留到后续章节。

完整代码可以保存为 `score_report.py` 运行：

```python
def select_valid_records(records):
    """保留有分数的记录；零分也是有效分数。"""
    valid = []
    for record in records:
        if record["score"] is not None:
            valid.append(record)
    return valid


def select_passed_records(records, threshold=60):
    """输入应为已经排除缺失分数的记录。"""
    passed = []
    for record in records:
        if record["score"] >= threshold:
            passed.append(record)
    return passed


def calculate_average(records):
    """没有有效记录时返回 None，区分无数据与平均零分。"""
    if not records:
        return None
    total = 0
    for record in records:
        total += record["score"]
    return total / len(records)


def print_report(records, threshold=60):
    valid = select_valid_records(records)
    passed = select_passed_records(valid, threshold)
    average = calculate_average(valid)

    print(f"测评人数：{len(records)}")
    print(f"有效成绩：{len(valid)}")
    print(f"缺失成绩：{len(records) - len(valid)}")
    print(f"及格人数：{len(passed)}（及格线 {threshold} 分）")

    if average is None:
        print("平均分：暂无数据")
        print("及格率：暂无数据")
    else:
        print(f"平均分：{average:.2f}")
        print(f"及格率：{len(passed) / len(valid):.1%}")

    names = []
    for record in passed:
        names.append(record["name"].strip())
    print(f"及格名单：{'、'.join(names) or '无'}")


records = [
    {"name": " 小林 ", "score": 85},
    {"name": "小周", "score": 58},
    {"name": "小陈", "score": 92},
    {"name": "小吴", "score": 0},
    {"name": "小郑", "score": None},
]
print_report(records)
```

```text
测评人数：5
有效成绩：4
缺失成绩：1
及格人数：2（及格线 60 分）
平均分：58.75
及格率：50.0%
及格名单：小林、小陈
```

这份报告的平均分与及格率都只以**有效成绩**为统计对象，缺失成绩单独计数；零分参与统计。筛选函数新建了列表，但列表里的记录仍引用原字典；当前函数只读取这些字典，不修改它们。

再改动数据，检查以下边界：

- 把记录改为空列表：平均分和及格率应显示“暂无数据”，不能发生除零。
- 所有人分数都是 `None`：仍然没有有效成绩。
- 只有一条零分记录：平均分为 `0.00`，不是“暂无数据”。
- 只有一条 60 分记录：按默认及格线应该及格。
- 把及格线设为 90：示例中只有小陈及格，但平均分不变。

**本节练习**：先遮住完整代码，自己写一版；再增加最高分输出，并妥善处理没有有效成绩的情况。

**过关标准**：能区分打印与返回，能用参数复用同一段逻辑，知道可变默认参数为什么有风险，能独立完成汇总脚本。
