# Python 语言内核：理解对象、协议与库的实现

本篇对应 **L4，节点 19–24**。蛇形图中这一行从右向左走，正文仍按编号递增。前置为 [3-地道Python](./3-地道Python.md)，示例以 **Python 3.12** 为验证环境，使用标准库。

目标是能读懂第三方库为什么可以像函数一样调用、像列表一样索引、像普通属性一样执行校验。先理解协议，再判断是否真的需要自定义行为；不把复杂技巧当作代码质量本身。

普通示例可独立运行，动态导入示例仅使用临时目录中的自建文件。

## 19｜对象与魔法方法

### 19.1 类型本身也是对象

```python
class Score:
    pass

record = Score()
print(type(record).__name__)
print(type(Score).__name__)
print(isinstance(record, Score))
```

```text
Score
type
True
```

对象具有身份、类型和状态。类也是对象，通常由 `type` 创建。变量持有对象的引用，不是为它创建一份独立副本。

双下划线方法也称特殊方法，参与 Python 语法和内置操作的实现。通常应让 `len(obj)`、`str(obj)` 等语法调用它们，不必在业务代码里到处手动调用魔法方法。

### 19.2 __repr__ 与 __str__

```python
class Score:
    def __init__(self, value):
        self.value = value

    def __repr__(self):
        return f"Score(value={self.value!r})"

    def __str__(self):
        return f"{self.value} 分"

score = Score(85)
print(score)
print(repr(score))
print([score])
```

```text
85 分
Score(value=85)
[Score(value=85)]
```

`str` 侧重易读展示，`repr` 侧重排错时识别对象。容器展示元素时通常使用 `repr`。不要把密码或令牌写进对象的默认表示，否则日志可能意外暴露它们。

### 19.3 相等比较与 NotImplemented

```python
class Score:
    def __init__(self, value):
        self.value = value

    def __eq__(self, other):
        if not isinstance(other, Score):
            return NotImplemented
        return self.value == other.value

print(Score(85) == Score(85))
print(Score(85) == 85)
```

```text
True
False
```

`NotImplemented` 表示“这组操作数不由当前方法处理”，让解释器尝试其他比较规则。它不同于 `NotImplementedError` 异常。

### 19.4 __hash__ 与不可变键

哈希集合要求：两个相等对象必须有相同的哈希值；对象作为键期间，影响比较和哈希的内容不应改变。只追求“可放进 set”而随意加哈希函数，可能破坏查找。

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class CaseKey:
    suite: str
    case_id: str

keys = {CaseKey("基础", "001"), CaseKey("基础", "001")}
print(len(keys))
```

```text
1
```

这里字段本身也是不可变字符串。`frozen=True` 不会自动冻结任意深层嵌套对象；包含列表等字段时，还要重新考虑是否能哈希。

定义 `__eq__` 而未适当定义 `__hash__` 的普通类通常会变成不可哈希，这是防止不一致的一种保护。

### 19.5 真值协议

Python 通常先尝试 `__bool__()`，再考虑 `__len__()`；都没有时对象默认真。

```python
class Results:
    def __init__(self, values):
        self.values = list(values)

    def __len__(self):
        return len(self.values)

print(bool(Results([])))
print(bool(Results([0])))
```

```text
False
True
```

第二个对象包含零分，但不是空集合。不要把“有记录”和“记录分数非零”混成一个判断。

**练习与验收**：为成绩对象定义易读表示和相等规则，解释它是否应该允许作为字典键。

## 20｜运算与属性协议

### 20.1 运算符重载

```python
class Points:
    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        if not isinstance(other, Points):
            return NotImplemented
        return Points(self.value + other.value)

    def __repr__(self):
        return f"Points({self.value})"

print(Points(30) + Points(55))
```

```text
Points(85)
```

`a + b` 涉及运算协议，并不在所有情况下都等价于只调用一次 `a.__add__(b)`；还有反向运算方法、子类优先级等规则。初学先设计清楚支持哪些类型，遇到不支持的类型返回 `NotImplemented`。

不要为了简短让 `+` 表示毫不相关的网络写入或删除动作。

### 20.2 __getitem__ 与切片

```python
class ScoreList:
    def __init__(self, values):
        self._values = list(values)

    def __getitem__(self, key):
        return self._values[key]

    def __len__(self):
        return len(self._values)

scores = ScoreList([85, 58, 92])
print(scores[0])
print(scores[1:])
print(len(scores))
```

```text
85
[58, 92]
3
```

索引传入整数，切片传入 `slice` 对象。例子委托给内部列表处理，并让切片返回普通列表；若想返回同类对象，需要显式定义。

### 20.3 __call__：让实例可以调用

```python
class Threshold:
    def __init__(self, minimum):
        self.minimum = minimum

    def __call__(self, score):
        return score >= self.minimum

check = Threshold(60)
print(check(85))
print(callable(check))
```

```text
True
True
```

有状态的检查器可以写成可调用对象，也可以用闭包。根据是否需要多项属性、多个方法及清楚的对象生命周期选择。

### 20.4 __getattr__、__getattribute__ 与 __setattr__

`__getattribute__` 参与常规属性读取；`__getattr__` 通常在正常查找失败后作为后备。二者不是可以随意互换的“获取属性函数”。

```python
class Config:
    def __init__(self, values):
        self._values = dict(values)

    def __getattr__(self, name):
        try:
            return self._values[name]
        except KeyError as exc:
            raise AttributeError(name) from exc

config = Config({"threshold": 60})
print(config.threshold)
print(hasattr(config, "missing"))
```

```text
60
False
```

属性不存在时应抛 `AttributeError`，让 `hasattr` 等工具正确识别。动态属性不是无成本的便利，可能让拼写错误更隐蔽；普通配置类往往更清楚。

重写 `__getattribute__` 时，内部取自身属性通常应使用 `object.__getattribute__`；重写 `__setattr__` 时可用 `object.__setattr__`。否则再次访问同一协议容易无限递归。

**练习与验收**：写一个支持索引和长度的结果容器，明确越界、切片和未知属性的行为。

## 21｜描述符与内存

### 21.1 描述符把属性行为复用到多个字段

实现 `__get__`、`__set__` 或 `__delete__` 的对象可以参与描述符协议，通常放在类属性位置。下面复用一套 0–100 分校验：

```python
class ScoreField:
    def __set_name__(self, owner, name):
        self.storage_name = "_" + name

    def __get__(self, instance, owner=None):
        if instance is None:
            return self
        return getattr(instance, self.storage_name)

    def __set__(self, instance, value):
        if isinstance(value, bool) or not isinstance(value, (int, float)):
            raise ValueError("分数必须是数值")
        if not 0 <= value <= 100:
            raise ValueError("分数超出范围")
        setattr(instance, self.storage_name, value)


class Record:
    score = ScoreField()

    def __init__(self, score):
        self.score = score

record = Record(85)
print(record.score)
try:
    record.score = 101
except ValueError as exc:
    print(exc)
```

```text
85
分数超出范围
```

`__set_name__` 得到字段名，赋值时执行校验，实际数据保存在实例中。不能把每条记录的分数直接存到共享的描述符对象上，否则不同实例可能互相覆盖。

### 21.2 数据描述符、非数据描述符与 property

提供 `__set__` 或 `__delete__` 的是数据描述符；仅提供读取行为的是非数据描述符。数据描述符通常优先于实例字典；非数据描述符通常可以被实例同名属性遮住。

`property` 和普通方法都与描述符机制有关。理解这一点有助于阅读 ORM 字段、校验框架和方法绑定代码，日常只维护一个属性时仍可先用 `property`。详细规则见 [Python 描述符指南](https://docs.python.org/3.12/howto/descriptor.html)。

### 21.3 __slots__ 的用途和限制

```python
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y

point = Point(1, 2)
print(point.x, point.y)
print(hasattr(point, "__dict__"))
try:
    point.label = "起点"
except AttributeError:
    print("不能添加未声明属性")
```

```text
1 2
False
不能添加未声明属性
```

槽可以限制属性布局，并在某些大量实例场景中降低内存开销；实际收益要测量。父类、子类是否提供实例字典会影响结果，不能把示例推广成所有继承结构的保证。

`__slots__` 不等于不可变，也不提供访问权限隔离。需要弱引用时，槽类还可能需要加入 `__weakref__`。

### 21.4 弱引用与内存观察

```python
import gc
import weakref

class Record:
    pass

record = Record()
reference = weakref.ref(record)
print(reference() is record)
del record
gc.collect()
print(reference() is None)
```

```text
True
True
```

弱引用不会单独阻止对象回收，适合某些缓存或观察关系。不要依赖析构时机来关闭文件；资源清理优先用 `with` 或显式生命周期。

`sys.getsizeof()` 通常只反映对象自身的浅层大小，不等于它引用的整个对象图占用。定位分配问题可以进一步学习 `tracemalloc`。

**练习与验收**：用描述符约束两个不同实例的分数，确认互不覆盖，并解释它与普通实例属性的区别。

## 22｜抽象类与元类

### 22.1 ABC：明确必须实现的接口

```python
from abc import ABC, abstractmethod

class Scorer(ABC):
    @abstractmethod
    def score(self, text):
        raise NotImplementedError

class LengthScorer(Scorer):
    def score(self, text):
        return len(text)

print(LengthScorer().score("Python"))
try:
    Scorer()
except TypeError:
    print("抽象类不能直接实例化")
```

```text
6
抽象类不能直接实例化
```

ABC 可以表达明确继承体系中的接口约束；Protocol 更常用于结构化静态检查。不要把“有方法”当成“业务行为一定正确”，正确性还需测试。

`ABC.register()` 注册虚拟子类不会给它注入方法，也不会自动完成接口实现。

### 22.2 type 可以动态创建类

```python
DynamicRecord = type("DynamicRecord", (), {"category": "成绩"})
record = DynamicRecord()
print(type(record).__name__)
print(record.category)
```

```text
DynamicRecord
成绩
```

这里传入类名、基类元组和属性字典。普通 `class` 语句更易读，动态创建只用于需要在运行时生成结构的明确场景。

### 22.3 元类与更轻量的替代

元类控制类的创建。读库时可能遇到 `class Model(metaclass=...)`，但新增类时注册名字这类需求，通常可以先考虑 `__init_subclass__`：

```python
class Plugin:
    registry = {}

    def __init_subclass__(cls, **kwargs):
        super().__init_subclass__(**kwargs)
        Plugin.registry[cls.__name__] = cls

class TextPlugin(Plugin):
    pass

print(Plugin.registry["TextPlugin"] is TextPlugin)
```

```text
True
```

类装饰器和 `__init_subclass__` 可以解决部分需求，不必立即使用元类。多继承下的元类兼容、方法解析顺序和类创建过程更复杂，应在需求出现时再深入。

**练习与验收**：为两种打分器定义接口；说明选择 ABC、Protocol 或普通鸭子类型的理由。

## 23｜导入机制

### 23.1 sys.modules 是模块缓存

```python
import importlib
import sys

first = importlib.import_module("json")
second = importlib.import_module("json")
print(first is second)
print(sys.modules["json"] is first)
```

```text
True
True
```

导入通常先利用缓存，再按查找器、加载器等机制定位并初始化模块。缓存不等于源码自动热更新。

`importlib.reload()` 重新执行模块代码也不会自动替换所有外部已保存的旧函数或旧类引用，不能把它当成完整的热重载系统。

### 23.2 从明确路径加载可信模块

```python
import importlib.util
import sys
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as folder:
    path = Path(folder) / "lesson_plugin.py"
    path.write_text("def score(text):\n    return len(text)\n", encoding="utf-8")
    name = "lesson_plugin_demo"
    spec = importlib.util.spec_from_file_location(name, path)
    if spec is None or spec.loader is None:
        raise ImportError("无法创建模块加载器")
    module = importlib.util.module_from_spec(spec)
    previous = sys.modules.get(name)
    sys.modules[name] = module
    try:
        spec.loader.exec_module(module)
        print(module.score("Python"))
    finally:
        if previous is None:
            sys.modules.pop(name, None)
        else:
            sys.modules[name] = previous
```

```text
6
```

这个例子只加载自己刚写入的文件。**加载模块会执行代码**，不能把用户上传的任意 `.py` 当作普通配置读取。正式插件系统还应明确允许的插件、接口与版本范围。

模块生成后需要重新搜索时，可以了解 `invalidate_caches()`；具体加载流程见 [importlib 文档](https://docs.python.org/3.12/library/importlib.html)。

### 23.3 常见定位问题

先检查解释器、`sys.path`、包名及同名文件，再检查循环导入。不要在多个文件里随意向 `sys.path` 塞相对目录来掩盖项目结构问题。

包内资源不一定是当前目录中的普通文件；需要读取安装包自带资料时，可以进一步学习 `importlib.resources`。

**练习与验收**：通过 `importlib.import_module` 加载一个标准库，解释为什么再次导入通常得到同一个模块对象。

## 24｜内省与调试

### 24.1 inspect：观察函数与对象

```python
import inspect


def average(scores, threshold=60):
    """示例接口。"""
    return sum(scores) / len(scores)

print(inspect.signature(average))
print(inspect.getdoc(average))
print(inspect.isfunction(average))
```

```text
(scores, threshold=60)
示例接口。
True
```

`getsource()` 在有可用源文件时可以读取源码，但内置函数、动态生成代码或某些交互环境不一定能取得源码。

观察属性也可能触发动态逻辑；`inspect.getattr_static()` 可在特定排查场景中避免常规动态属性查找，但返回的可能是描述符本身，而不是执行后的值。

### 24.2 dis：理解执行形态，不背字节码

```python
import dis


def increment(value):
    return value + 1

instructions = list(dis.get_instructions(increment))
print(any(item.opname == "RETURN_VALUE" for item in instructions))
```

```text
True
```

字节码会随 Python 版本和实现变化，不应把某个版本的指令序列当作语言语义。只有当它有助于解释具体问题时再查看。

### 24.3 pdb 与最小复现

在自己的脚本中加入 `breakpoint()` 可进入调试器。常用操作是 `n` 执行下一行、`s` 进入调用、`p 表达式` 查看值、`c` 继续、`q` 退出。这里不自动运行断点示例，避免脚本停住等待输入。

排查顺序建议是：保留错误栈、缩小输入、写出预期与实际、检查对象和调用参数，最后再研究协议或底层实现。能够用一个十行示例复现的问题，比堆满整个项目的日志更容易分析。

### 24.4 综合练习：支持集合协议的成绩对象

```python
class ScoreBook:
    def __init__(self, scores):
        values = tuple(scores)
        for value in values:
            if isinstance(value, bool) or not isinstance(value, (int, float)):
                raise ValueError("成绩必须是数值")
            if not 0 <= value <= 100:
                raise ValueError("成绩超出范围")
        self._scores = values

    def __len__(self):
        return len(self._scores)

    def __iter__(self):
        return iter(self._scores)

    def __getitem__(self, key):
        return self._scores[key]

    def __repr__(self):
        return f"ScoreBook({self._scores!r})"

    @property
    def average(self):
        return sum(self._scores) / len(self) if self else None

book = ScoreBook([85, 58, 92, 0])
print(len(book), book[0])
print(list(book))
print(book.average)
print(ScoreBook([]).average)
```

```text
4 85
[85, 58, 92, 0]
58.75
None
```

检查切片返回什么、迭代能否重复、非法分数是否被拒绝。这个对象不需要实现每一种魔法方法，也不应因为学过元类就强行加入元类。
