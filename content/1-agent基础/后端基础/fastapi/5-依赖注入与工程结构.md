## 1｜Depends：把「公共准备」抽出去

**这一节解决的问题**：分页参数、假登录用户、共享资源，怎样避免在每个接口里复制粘贴？

### 1.1 最简单的依赖

```python
from typing import Annotated
from fastapi import Depends, FastAPI, Query

app = FastAPI()


def pagination(
    page: Annotated[int, Query(ge=1)] = 1,
    page_size: Annotated[int, Query(ge=1, le=100)] = 10,
) -> dict:
    return {"page": page, "page_size": page_size, "offset": (page - 1) * page_size}


@app.get("/scores")
def list_scores(page_data: Annotated[dict, Depends(pagination)]):
    return {"query": page_data, "items": []}
```

访问 `/scores?page=2&page_size=20` 时，FastAPI 先调用 `pagination`，再把返回值注入 `page_data`。路径操作函数只关心业务。

### 1.2 依赖里也可以抛错

```python
from fastapi import Header, HTTPException


def get_current_user(x_api_key: Annotated[str | None, Header()] = None) -> dict:
    if x_api_key != "demo-key":
        raise HTTPException(status_code=401, detail="无效的 API Key")
    return {"name": "助教", "role": "staff"}


@app.get("/admin/stats")
def admin_stats(user: Annotated[dict, Depends(get_current_user)]):
    return {"user": user, "avg_score": 78.5}
```

未带正确 `X-Api-Key` 时直接 401，业务函数不会执行。这是入门级「鉴权」演示，生产环境请换正规方案（OAuth2 / JWT 等）。

### 1.3 依赖可以嵌套

```python
def get_db():
    db = {"scores": []}  # 演示用；真实项目可能是会话工厂
    try:
        yield db
    finally:
        # 关闭连接等清理工作
        pass


def get_score_service(db: Annotated[dict, Depends(get_db)]):
    return {"db": db}


@app.get("/ready")
def ready(svc: Annotated[dict, Depends(get_score_service)]):
    return {"ok": True, "keys": list(svc["db"].keys())}
```

带 `yield` 的依赖适合「先获取资源，请求结束后清理」。入门先会用普通 `return` 依赖即可。

## 2｜APIRouter：按模块挂路由

**这一节解决的问题**：所有接口都写在 `main.py` 里会膨胀，怎样拆开？

### 2.1 定义路由模块

`routers/scores.py`：

```python
from typing import Annotated
from fastapi import APIRouter, HTTPException, status
from pydantic import BaseModel, Field

router = APIRouter(prefix="/scores", tags=["成绩"])


class ScoreCreate(BaseModel):
    name: str
    score: int = Field(ge=0, le=100)


class ScoreOut(BaseModel):
    id: int
    name: str
    score: int
    passed: bool


_STORE: dict[int, ScoreOut] = {}
_NEXT_ID = 1


@router.get("", response_model=list[ScoreOut])
def list_scores():
    return list(_STORE.values())


@router.post("", response_model=ScoreOut, status_code=status.HTTP_201_CREATED)
def create_score(payload: ScoreCreate):
    global _NEXT_ID
    row = ScoreOut(
        id=_NEXT_ID,
        name=payload.name,
        score=payload.score,
        passed=payload.score >= 60,
    )
    _STORE[_NEXT_ID] = row
    _NEXT_ID += 1
    return row


@router.get("/{score_id}", response_model=ScoreOut)
def get_score(score_id: int):
    row = _STORE.get(score_id)
    if row is None:
        raise HTTPException(status_code=404, detail="记录不存在")
    return row
```

### 2.2 在应用里挂载

`main.py`：

```python
from fastapi import FastAPI
from routers import scores

app = FastAPI(title="成绩 API")
app.include_router(scores.router)


@app.get("/health")
def health():
    return {"status": "ok"}
```

效果：

- 列表：`GET /scores`
- 创建：`POST /scores`
- 详情：`GET /scores/{score_id}`

`tags` 会在 `/docs` 里分组，项目变大后很好找。

## 3｜CORS：让浏览器前端能调你的 API

浏览器从 `http://localhost:5173` 调 `http://127.0.0.1:8000` 属于跨域，需服务端声明允许：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],  # 开发时写明前端地址
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

注意：

- Apifox / `curl` **不受**浏览器 CORS 限制；CORS 主要影响浏览器里的前端页。
- 生产环境不要随意 `allow_origins=["*"]` 再配合 `allow_credentials=True`。

## 4｜中间件：请求进出时统一做事

```python
import time
from fastapi import Request


@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)
    response.headers["X-Process-Time"] = f"{time.perf_counter() - start:.4f}"
    return response
```

适合：日志、计时、简单鉴权门槛。复杂业务校验仍优先放在 Depends 或路径函数里，便于测试和复用。

## 5｜推荐目录（入门版）

```text
score-api/
├── .venv/
├── requirements.txt
├── main.py                 # 创建 app、挂路由、挂中间件
├── schemas/                # Pydantic 模型（可选拆分）
│   └── score.py
├── routers/
│   ├── __init__.py
│   └── scores.py
└── deps.py                 # 公共 Depends（可选）
```

原则：

1. **`main.py` 保持瘦**：组装，不堆业务；
2. **按资源分 router**：`scores`、`students`……；
3. **模型可单独放**：多处复用时再拆 `schemas/`；
4. **先内存后数据库**：逻辑跑通再换持久化，避免一上来被 ORM 淹没。

更大项目还会有 `services/`（业务）、`repositories/`（存取），等 CRUD 写熟再引入。

## 6｜生命周期：启动与关闭时做事

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI


@asynccontextmanager
async def lifespan(app: FastAPI):
    # 启动时：加载配置、连接池等
    app.state.ready = True
    yield
    # 关闭时：释放资源
    app.state.ready = False


app = FastAPI(lifespan=lifespan)
```

旧版 `on_event("startup")` 仍能见到，新代码优先用 `lifespan`。
