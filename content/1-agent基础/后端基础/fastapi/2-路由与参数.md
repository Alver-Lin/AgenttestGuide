## 1｜路径操作：URL + 方法

**这一节解决的问题**：怎样告诉 FastAPI「这个地址用哪种方法访问」？

### 1.1 常用装饰器

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/scores")
def list_scores():
    return [{"name": "小林", "score": 85}]


@app.post("/scores")
def create_score():
    return {"ok": True}


@app.put("/scores/{score_id}")
def replace_score(score_id: int):
    return {"score_id": score_id}


@app.patch("/scores/{score_id}")
def update_score(score_id: int):
    return {"score_id": score_id}


@app.delete("/scores/{score_id}")
def delete_score(score_id: int):
    return {"deleted": score_id}
```

同一路径可以挂多个方法：`GET /scores` 查列表，`POST /scores` 创建，互不冲突。

### 1.2 路径顺序要注意

更具体的路径要写在更宽泛的路径**前面**，否则可能被先匹配走：

```python
@app.get("/scores/summary")
def scores_summary():
    return {"avg": 80}


@app.get("/scores/{score_id}")
def get_score(score_id: int):
    return {"score_id": score_id}
```

若先声明 `/{score_id}`，请求 `/scores/summary` 时，`summary` 可能被当成 `score_id` 去解析并报校验错误。

## 2｜路径参数

**这一节解决的问题**：资源编号这类「嵌在 URL 路径里」的值怎么取？

### 2.1 基本用法

花括号里的名字对应函数参数：

```python
@app.get("/scores/{score_id}")
def get_score(score_id: int):
    return {"score_id": score_id, "name": "小林", "score": 85}
```

访问 `GET /scores/3` 时，`score_id` 为整数 `3`。若访问 `/scores/abc`，FastAPI 返回 **422**，说明类型对不上。

### 2.2 用 Path 增加约束与说明

```python
from typing import Annotated
from fastapi import FastAPI, Path

app = FastAPI()


@app.get("/scores/{score_id}")
def get_score(
    score_id: Annotated[int, Path(title="成绩记录 ID", ge=1, description="必须是正整数")],
):
    return {"score_id": score_id}
```

`ge=1` 表示 greater or equal，即 ≥ 1。文档里会出现这些说明，校验失败同样是 422。

常见约束：`gt` / `ge` / `lt` / `le`（大小）、`min_length` / `max_length`（字符串长度）。

## 3｜查询参数

**这一节解决的问题**：筛选、分页这类「URL `?` 后面」的参数怎么声明？

### 3.1 默认就是查询参数

函数里**不属于路径**的简单类型参数，默认从 Query String 读取：

```python
@app.get("/scores")
def list_scores(passed_only: bool = False, min_score: int = 0):
    data = [
        {"name": "小林", "score": 85},
        {"name": "小王", "score": 55},
    ]
    result = [row for row in data if row["score"] >= min_score]
    if passed_only:
        result = [row for row in result if row["score"] >= 60]
    return result
```

示例请求：

```http
GET /scores?passed_only=true&min_score=60
```

布尔值可写 `true` / `false`、`1` / `0` 等，FastAPI 会帮你转换。

### 3.2 可选与必填

- 有默认值 → **可选**查询参数。
- 无默认值 → **必填**；缺了会 422。

```python
from typing import Annotated
from fastapi import Query


@app.get("/search")
def search(
    q: Annotated[str, Query(min_length=1, max_length=50, description="姓名关键字")],
    limit: Annotated[int, Query(ge=1, le=100)] = 10,
):
    return {"q": q, "limit": limit}
```

这里 `q` 必填，`limit` 默认 10。

### 3.3 路径参数 vs 查询参数（对照）

| | 路径参数 | 查询参数 |
|--|----------|----------|
| 位置 | `/scores/3` 里的 `3` | `/scores?min_score=60` 里的 `min_score` |
| 典型用途 | 资源身份（id） | 筛选、排序、分页 |
| 声明方式 | 路径里 `{name}` + 同名参数 | 非路径的函数参数，或显式 `Query` |

## 4｜请求头与其他位置

### 4.1 Header

```python
from typing import Annotated
from fastapi import Header


@app.get("/whoami")
def whoami(x_user_token: Annotated[str | None, Header()] = None):
    return {"token_present": x_user_token is not None}
```

HTTP 头名不区分大小写；Python 里用下划线 `x_user_token`，对应请求头 `X-User-Token`（FastAPI 默认会转换）。

### 4.2 多类参数可以组合

```python
@app.get("/courses/{course_id}/scores")
def course_scores(
    course_id: int,
    passed_only: bool = False,
    x_request_id: Annotated[str | None, Header()] = None,
):
    return {
        "course_id": course_id,
        "passed_only": passed_only,
        "request_id": x_request_id,
    }
```

FastAPI 按**参数来源**分别取值：路径里的进路径参数，其余简单类型默认进查询参数，标了 `Header` 的进请求头。请求体（JSON Body）下一篇再用 Pydantic 模型声明。

## 5｜422：参数校验失败长什么样

故意传错类型，例如 `GET /scores/abc`（而 `score_id` 声明为 `int`），响应状态码为 **422 Unprocessable Entity**，正文类似：

```json
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "score_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "abc"
    }
  ]
}
```

阅读要点：

- `loc`：错在哪（path / query / body + 字段名）；
- `msg` / `type`：什么错；
- `input`：客户端实际传了什么。

调试时先看状态码是不是 422，再读 `detail`，比只盯着自己的业务逻辑更快定位。
