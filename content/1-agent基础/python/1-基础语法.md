## 1. 环境、运行与缩进

### 1.1 解释器、编辑器与工作目录

**定义**：解释器是真正执行 `.py` 的程序；编辑器 / IDE 只负责编辑；工作目录是终端「当前所在文件夹」，相对路径相对它解析。

**类比**：解释器是发动机，编辑器是方向盘；工作目录是你现在站的路口——说「前面那家店」要以你站的位置为准。

**代码表现**：

```python
import sys

print(sys.executable)  # 当前用的解释器路径
```

```text
/usr/local/bin/python3
```

（路径因机器而异，关键是确认「到底用的哪一个」。）

**使用场景**：脚本跑不起来、找不到文件、装了多个 Python 时，先确认「用的是哪个解释器、从哪个目录运行」。

**场景代码**：

```bash
python --version
python -c "import sys; print(sys.executable)"
python hello.py
```

```text
Python 3.12.x
/usr/local/bin/python3
```

### 1.2 运行方式

**定义**：同一段 Python，可以用交互环境临时试、用脚本文件重复跑、或用 `-c` 执行一行。

**类比**：草稿纸（交互）、作业本（脚本）、便利贴（`-c`）。

**代码表现**：

```bash
python                  # 进入 >>> 交互；exit() 退出
python hello.py         # 跑文件
python -c "print(1+1)"  # 跑一行
```

```text
# python -c "print(1+1)" 的结果：
2
```

**使用场景**：试表达式用交互；正式程序存 `.py`；临时验证一句用 `-c`。

**场景代码**（`hello.py`）：

```python
print("你好，Python！")
```

```bash
python hello.py
```

```text
你好，Python！
```

### 1.3 缩进与注释

**定义**：缩进表示代码块归属；`#` 开头是注释，解释器忽略。约定每层 **4 个空格**，不混用 Tab。

**类比**：缩进像公文的层级缩格——缩在谁下面，就属于谁；注释像便利贴，给人看、机器不读。

**代码表现**：

```python
# 这是注释
score = 100
if score >= 0:
    print(score)   # 属于 if
else:
    print(-score)  # 属于 else
```

```text
100
```

**使用场景**：`if` / `for` / `def` 等所有「冒号后面的一块代码」都靠缩进界定。

**场景代码**：

```python
predict = "通过"
if predict == "通过":
    result = 1.0
else:
    result = 0.0
print(result)
```

```text
1.0
```

### 1.4 小结

先确认解释器与工作目录；缩进错了，逻辑或语法会立刻出问题。

## 2. 数据类型与变量

### 2.1 变量与对象

**定义**：变量名是绑在对象上的**标签**；类型属于对象，不属于「盒子」。赋值是换标签，不是改盒子封印。

**类比**：名字像便利贴，对象像行李。换贴不等于换行李类型；一张贴可以撕下来贴到另一件行李上。

**代码表现**：

```python
name = "小明"       # str
age = 18            # int
height = 1.75       # float
is_student = True   # bool
address = None      # 尚无值
print(type(age).__name__)
```

```text
int
```

**使用场景**：保存文本、分数、开关、暂缺值；后文评测里到处都是这些类型。

**场景代码**：

```python
predict = "  通过 "
expect = "通过"
score = 1.0 if predict.strip() == expect else 0.0
print(score)
```

```text
1.0
```

| 类型 | 可变？ | 常见用途 |
| --- | --- | --- |
| `int` / `float` / `bool` | 不可变 | 计数、分数、开关 |
| `str` | 不可变 | Prompt、预测文本 |
| `list` | 可变 | 有序一批数据 |
| `dict` | 可变 | 键→值映射 |
| `set` | 可变 | 去重、交并差 |
| `tuple` | 不可变 | 固定打包 |
| `None` | — | 缺失值 |

### 2.2 列表 list

**定义**：有序、可变的序列，用 `[]` 表示，按下标访问（从 0 开始）。

**类比**：排队名单——有先后，可以在队尾加人、改某一格。

**代码表现**：

```python
cases = ["准确率", "工具调用"]
cases.append("拒答")
print(cases[0])
print(len(cases))
print(cases)
```

```text
准确率
3
['准确率', '工具调用', '拒答']
```

**使用场景**：用例列表、一批分数、需要保持顺序的记录。

**场景代码**：

```python
scores = [0.9, 0.7, 0.85]
passed = []
for score in scores:
    if score >= 0.8:
        passed.append(score)
print(passed)
```

```text
[0.9, 0.85]
```

### 2.3 字典 dict

**定义**：键 → 值的映射，用 `{键: 值}` 表示，用键查找，不靠位置。

**类比**：通讯录——用姓名找电话，不是翻第几行。

**代码表现**：

```python
metrics = {"accuracy": 0.9, "latency_ms": 120}
print(metrics["accuracy"])
print(metrics.get("bleu", 0.0))  # 没有键时给默认
metrics["tool_ok"] = 0.85
print(metrics)
```

```text
0.9
0.0
{'accuracy': 0.9, 'latency_ms': 120, 'tool_ok': 0.85}
```

**使用场景**：配置、指标表、解析后的 JSON 对象。

**场景代码**：

```python
report = {"case_id": "1", "score": 0.92}
print(f"{report['case_id']} → {report['score']}")
```

```text
1 → 0.92
```

### 2.4 集合 set

**定义**：不重复元素的无序集合，自动去重；空集合写 `set()`（`{}` 是空字典）。

**类比**：入场手环——同一个人只算一次；不保证排队顺序。

**代码表现**：

```python
tags = {"评测", "Agent", "评测"}
print(tags)
print("Agent" in tags)
```

```text
{'评测', 'Agent'}
True
```

（集合无序，打印时元素先后可能不同，内容等价即可。）

**使用场景**：标签去重、求两个集合的交/并/差。

**场景代码**：

```python
predicted = {"准确率", "拒答"}
required = {"准确率", "工具调用"}
print(predicted & required)  # 交集：都提到的
print(required - predicted)  # 差集：缺了的
```

```text
{'准确率'}
{'工具调用'}
```

### 2.5 命名与赋值

**定义**：名字含字母数字下划线且不以数字开头；推荐 `snake_case`。赋值、解包、交换都是绑定操作。

**类比**：起名要合法；`x, y = y, x` 像两手交换杯子。

**代码表现**：

```python
score = 90
score = "优秀"           # 可换绑，但不建议乱换类型
a = b = 0
x, y = 1, 2
x, y = y, x
first, *rest = [1, 2, 3]
print(score, a, b, x, y, first, rest)
```

```text
优秀 0 0 2 1 1 [2, 3]
```

**使用场景**：一次拆开多个返回值；交换两个变量；拆「头 + 剩余」。

**场景代码**：

```python
case_id, score = ("case-01", 0.91)
print(case_id, score)
```

```text
case-01 0.91
```

### 2.6 类型转换

**定义**：用 `int` / `float` / `str` / `bool` 等把一种对象转成另一种；失败常抛 `ValueError`。

**类比**：把纸条上的 `"18"` 读成数字 18，才能做加减。

**代码表现**：

```python
print(int("42"))
print(float("3.14"))
print(str(18))
print(bool(0))
print(bool("False"))   # 非空字符串都是真
```

```text
42
3.14
18
False
True
```

**使用场景**：`input()`、文件、模型输出拿到的往往是字符串，要先转换再计算。

**场景代码**：

```python
raw = "0.85"
score = float(raw)
print(score >= 0.8)
```

```text
True
```

### 2.7 `==` 与 `is`

**定义**：`==` 比内容相不相等；`is` 比是不是内存里同一个对象。空值判断用 `is None`。

**类比**：`==` 问「长得一样吗」；`is` 问「是不是同一件衣服」。

**代码表现**：

```python
a = [1]
b = a
c = [1]
print(a == b, a is b)
print(a == c, a is c)
print(None is None)
```

```text
True True
True False
True
```

**使用场景**：比分数、比文本用 `==`；判断「有没有赋值 / 是否缺失」用 `is None`。

**场景代码**：

```python
result = None
if result is None:
    result = {"score": 0.0}
print(result)
```

```text
{'score': 0.0}
```

### 2.8 浮点精度

**定义**：二进制浮点有表示误差；严格相等可能失败，比较常用容差。

**类比**：用有限位小数写 1/3，永远写不完，相加可能对不齐。

**代码表现**：

```python
import math

print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3))
```

```text
False
True
```

**使用场景**：分数比较、阈值判断；金额更建议整数「分」或 `Decimal`。

**场景代码**：

```python
import math

got = 0.1 + 0.2
print(math.isclose(got, 0.3, rel_tol=1e-9))
```

```text
True
```

### 2.9 小结

名字是标签；有序用 list，按名查找用 dict，去重用 set；比内容用 `==`，比身份用 `is`。

## 3. 字符串

**定义**：不可变的文本序列；「修改」都会产生新字符串。

**类比**：刻好的碑文——要改字就另刻一块，原碑不变。

### 3.1 索引、切片、成员

**定义**：`s[i]` 取单字符；`s[a:b]` 切片（含 a 不含 b）；`in` 判断子串是否出现。

**类比**：书架上取第几本；切片像「从第 a 本取到第 b 本之前」。

**代码表现**：

```python
title = "Agent 评测入门"
print(title[0])
print(title[-2:])
print(title[0:5])
print("评测" in title)
```

```text
A
入门
Agent
True
```

**使用场景**：截取模型输出片段、判断是否包含关键字。

**场景代码**：

```python
text = "最终答案：通过"
print("通过" in text)
print(text[-2:])
```

```text
True
通过
```

### 3.2 常用方法

**定义**：`strip` / `lower` / `split` / `join` / `replace` 等返回新字符串，不改原对象。

**类比**：复印件上涂改——原件不动，你拿着改过的复印件。

**代码表现**：

```python
s = "  Hello, Agent  "
print(s.strip())
print("a,b,c".split(","))
print("-".join(["a", "b"]))
```

```text
Hello, Agent
['a', 'b', 'c']
a-b
```

**使用场景**：清洗预测文本空白、按逗号拆字段、再拼回去。

**场景代码**：

```python
predict = "  通过\n"
expect = "通过"
print(predict.strip() == expect)
```

```text
True
```

### 3.3 格式化：f-string

**定义**：`f"...{表达式}..."` 把变量嵌进字符串；可写格式如 `.2%`。

**类比**：填空题模板，空里填当前算出来的值。

**代码表现**：

```python
model = "gpt-test"
score = 0.876
print(f"模型={model}, 分数={score:.2%}")
```

```text
模型=gpt-test, 分数=87.60%
```

**使用场景**：拼 Prompt、打日志、生成报告行。

**场景代码**：

```python
case_id = "c01"
score = 0.91
line = f"| {case_id} | {score:.2f} |"
print(line)
```

```text
| c01 | 0.91 |
```

### 3.4 小结

字符串不可变；比较前常先 `strip`；展示与拼接优先 f-string。

## 4. 运算、分支与循环

### 4.1 运算符

**定义**：算术、比较、逻辑、成员、身份等符号，用来计算与判断。

**类比**：计算器按键 + 判断题里的「且 / 或 / 非」。

**代码表现**：

```python
print(7 / 2, 7 // 2)
print(0 <= 82 <= 100)
print("" or "默认名")  # 空串是假
```

```text
3.5 3
True
默认名
```

**使用场景**：算分、判断是否及格、检查键是否在字典里。

**场景代码**：

```python
score = 0.85
ok = score >= 0.8 and score <= 1.0
print(ok)
```

```text
True
```

| 类别 | 写法 | 易错点 |
| --- | --- | --- |
| 算术 | `+ - * / // % **` | `/` 真除；`//` 向负无穷取整 |
| 比较 | `== != < <= > >=` | 可链式 |
| 逻辑 | `and or not` | `or` 会误伤合法 `0` / `""` |
| 成员 | `in` / `not in` | 对 dict 查的是键 |

### 4.2 条件分支

**定义**：按条件选择执行路径；`if / elif / else` 自上而下匹配，命中即停。

**类比**：多层关卡——过了这一关就出关，不再问下一关。

**代码表现**：

```python
score = 82
if score >= 90:
    level = "优秀"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"
print(level)
```

```text
及格
```

**使用场景**：分数分档、预测是否通过、命令字分流。

**场景代码**：

```python
predict = "我无法回答"
if "无法" in predict or "拒绝" in predict:
    label = "拒答"
else:
    label = "正常"
print(label)
```

```text
拒答
```

三元（二选一短赋值）：

```python
score = 82
status = "通过" if score >= 60 else "未通过"
print(status)
```

```text
通过
```

`match`（3.10+，离散取值）：

```python
command = "run"
match command:
    case "run":
        action = "执行评测"
    case "list" | "ls":
        action = "列出任务"
    case _:
        action = "未知命令"
print(action)
```

```text
执行评测
```

### 4.3 循环

**定义**：重复执行；`for` 遍历可迭代对象，`while` 按条件重复。

**类比**：`for` 像按名册逐个点名；`while` 像「还有剩余次数就继续做」。

**代码表现**：

```python
for name in ["准确率", "拒答"]:
    print(name)

for i in range(3):  # 0,1,2
    print(i)

remaining = 3
while remaining > 0:
    remaining -= 1
print("remaining=", remaining)
```

```text
准确率
拒答
0
1
2
remaining= 0
```

**使用场景**：遍历用例、固定重试次数、两列数据对齐处理。

**场景代码**：

```python
names = ["小明", "小红"]
scores = [80, 90]
for index, (name, score) in enumerate(zip(names, scores), start=1):
    print(f"{index}. {name}={score}")
```

```text
1. 小明=80
2. 小红=90
```

`break` 结束整个循环；`continue` 跳过本轮剩余语句：

```python
for score in [0.2, 0.91, 0.55]:
    if score < 0.6:
        continue
    if score >= 0.9:
        print("高分", score)
        break
```

```text
高分 0.91
```

### 4.4 小结

运算符负责算与判；分支命中即停；循环先想清「遍历」还是「按条件重复」。

## 5. 列表与元组

### 5.1 列表操作

**定义**：列表支持追加、插入、弹出、排序等；许多原地方法返回 `None`。

**类比**：白板上的待办清单，可以擦改、末尾追加。

**代码表现**：

```python
cases = ["准确率", "工具调用"]
cases.append("拒答")
cases.insert(1, "幻觉")
last = cases.pop()
print(cases)
print(last)
print(sorted([3, 1, 2]))   # 新列表
print([3, 1, 2].sort())    # 原地排序，返回 None
```

```text
['准确率', '幻觉', '工具调用']
拒答
[1, 2, 3]
None
```

**使用场景**：动态收集用例名、维护待跑队列。

**场景代码**：

```python
queue = ["case-1", "case-2"]
done = []
while queue:
    current = queue.pop(0)
    done.append(current)
print(done)
```

```text
['case-1', 'case-2']
```

### 5.2 元组

**定义**：有序不可变序列；单元素必须写 `(42,)`。

**类比**：塑封好的套装——顺序固定，不能拆改单件。

**代码表现**：

```python
point = (10, 20)
name, score = ("welcome", 0.91)
singleton = (42,)
print(point)
print(name, score)
print(singleton)
```

```text
(10, 20)
welcome 0.91
(42,)
```

**使用场景**：函数返回多个值、当字典键的组成部分、固定字段打包。

**场景代码**：

```python
def score_pair(predict, expect):
    exact = predict.strip() == expect.strip()
    return exact, abs(len(predict) - len(expect))


ok, diff = score_pair("通过", "通过")
print(ok, diff)
```

```text
True 0
```

### 5.3 小结

要改内容用列表；固定打包 / 多返回值用元组；`sort()` 返回 `None`。

## 6. 字典与集合

### 6.1 字典遍历与更新

**定义**：用 `items()` 同时取键值；赋值即新增或覆盖。

**类比**：表格两列：栏目名和内容，改某一格或加一行。

**代码表现**：

```python
metrics = {"accuracy": 0.9}
metrics["latency_ms"] = 120
for key, value in metrics.items():
    print(key, value)
```

```text
accuracy 0.9
latency_ms 120
```

**使用场景**：汇总指标、逐字段写报告。

**场景代码**：

```python
row = {"id": "1", "score": 0.0}
row["score"] = 0.92
print(row.get("score"), row.get("bleu", 0.0))
```

```text
0.92 0.0
```

### 6.2 集合运算

**定义**：`&` 交、`|` 并、`-` 差。

**类比**：两堆标签贴纸，看重叠、合并、还缺什么。

**代码表现**：

```python
a = {"评测", "Agent"}
b = {"评测", "指标"}
print(a & b)
print(a | b)
print(b - a)
```

```text
{'评测'}
{'评测', 'Agent', '指标'}
{'指标'}
```

（并集打印顺序可能因机器而异。）

**使用场景**：必选标签是否齐全、预测标签与标准标签对比。

**场景代码**：

```python
must = {"准确率", "安全"}
got = {"准确率", "拒答"}
missing = must - got
print(missing)
```

```text
{'安全'}
```

### 6.3 如何选结构

**定义**：按「数据关系」选容器，而不是随便选一种。

**类比**：钉子用锤子、螺丝用改锥。

**代码表现**：见下表与场景代码。

**使用场景**：

| 需求 | 优先 |
| --- | --- |
| 有顺序、常追加 | `list` |
| 按名字查 | `dict` |
| 唯一性 / 交并差 | `set` |
| 少量固定字段 | `tuple` |

**场景代码**：

```python
cases = ["c1", "c2"]                 # list：有序用例
report = {"c1": 0.9, "c2": 0.7}      # dict：id→分
flags = set(cases)                   # set：快速判断是否存在
print("c1" in flags, report["c1"])
```

```text
True 0.9
```

### 6.4 小结

dict 用 `get` 防缺键；set 去重；选错结构后面会越写越拧。

## 7. 函数入门

**定义**：函数是可复用的代码块：接收参数，返回结果（默认 `None`）。

**类比**：一台小机器——投料（参数），出货（返回值）；尽量别在机器里顺便广播大喇叭（`print`）。

### 7.1 定义与调用

**定义**：`def 名(参数):` 定义；`名(实参)` 调用；`return` 交出结果。

**类比**：先设计图纸（def），再按图纸开工（调用）。

**代码表现**：

```python
def score_case(predict: str, expect: str, weight: float = 1.0) -> float:
    """简单精确匹配打分。"""
    hit = 1.0 if predict.strip() == expect.strip() else 0.0
    return hit * weight


print(score_case("通过", "通过"))
print(score_case(predict="失败", expect="通过", weight=0.5))
```

```text
1.0
0.0
```

**使用场景**：打分、清洗文本、拼 Prompt——同一逻辑多处调用。

**场景代码**：

```python
def normalize(text: str) -> str:
    return text.strip().lower()


print(normalize("  OK \n") == "ok")
```

```text
True
```

类型标注给人看，运行时默认不强制检查。没有 `return` 就返回 `None`。`return a, b` 实际是一个元组。

好习惯：函数只算结果；需要展示时在外面 `print(...)`。函数内乱 `print` 会刷屏、难测、难嵌入批处理，还容易只打印忘了 `return`。

### 7.2 位置参数、关键字参数、可变参数

**定义**：

| 名称 | 定义 |
| --- | --- |
| 位置参数 | 按顺序传入，不写参数名 |
| 关键字参数 | `名字=值` 传入 |
| 可变参数 | `*args` 收位置成元组；`**kwargs` 收关键字成字典 |

**类比**：位置=排队；关键字=填表；可变=自助袋（事先不知装几样）。

**代码表现**：

```python
def greet(name, title="同学"):
    return f"{title}{name}"


print(greet("小明"))
print(greet("小明", "老师"))
print(greet(name="小红", title="老师"))
```

```text
同学小明
老师小明
老师小红
```

**使用场景**：参数个数固定用普通参数；个数不定（多标签、多段日志、可选配置）用可变参数。

**场景代码**（个数不固定的具体例子）：

```python
def average(*scores):
    if not scores:
        return 0.0
    return sum(scores) / len(scores)


print(average(0.9, 0.8))            # 这次 2 个
print(average(0.9, 0.8, 0.7, 1.0))  # 这次 4 个
```

```text
0.85
0.85
```

```python
def merge_tags(*items, **options):
    prefix = options.get("prefix", "")
    return [prefix + tag for tag in sorted(set(items))]


print(merge_tags("评测", "Agent", "评测", prefix="#"))
```

```text
['#Agent', '#评测']
```

仅关键字栅栏（`*` 后必须写名字）：

```python
def total_price(price, quantity=1, *, discount=1.0):
    return price * quantity * discount


print(total_price(10, 2, discount=0.8))
```

```text
16.0
```

解包调用（与定义方向相反）：

```python
vals = [10, 2]
opt = {"discount": 0.8}
print(total_price(*vals, **opt))
```

```text
16.0
```

### 7.3 默认参数陷阱

**定义**：默认值在**定义时求值一次**；可变对象作默认值会在多次调用间共享。

**类比**：默认参数像办公室共用的草稿本——每人「以为」拿新的，其实翻的是同一本。

**代码表现**（错误）：

```python
def bad_add(item, bucket=[]):
    bucket.append(item)
    return bucket


print(bad_add("a"))
print(bad_add("b"))
```

```text
['a']
['a', 'b']
```

（第二次调用仍带着第一次的内容。）

**使用场景**：任何「可选列表 / 字典参数」都应避免 `[]` / `{}` 直接当默认值。

**场景代码**（正确）：

```python
def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket


print(add_item("a"))
print(add_item("b"))
```

```text
['a']
['b']
```

### 7.4 lambda

**定义**：只能写单个表达式的匿名函数，常作 `key=` 回调。

**类比**：一次性的临时便签公式，写长了就该改成正式函数名。

**代码表现**：

```python
cases = [{"name": "b", "score": 0.7}, {"name": "a", "score": 0.9}]
cases.sort(key=lambda item: item["score"], reverse=True)
print(cases)
```

```text
[{'name': 'a', 'score': 0.9}, {'name': 'b', 'score': 0.7}]
```

**使用场景**：排序、取最大最小时的短 key；复杂逻辑改用 `def`。

**场景代码**：

```python
rows = [{"id": "1", "score": 0.5}, {"id": "2", "score": 0.9}]
best = max(rows, key=lambda row: row["score"])
print(best["id"])
```

```text
2
```

### 7.5 小结

| 点 | 记住 |
| --- | --- |
| 函数 | 只返回结果，少在内部 `print` |
| 传参 | 位置 / 关键字 / `*args` / `**kwargs` |
| 默认值 | 不用可变对象 |
| lambda | 只写超短表达式 |
