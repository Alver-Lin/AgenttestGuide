## 1. 推导式、迭代器与生成器

### 1.1 推导式

```python
nums = [1, 2, 3, 4, 5]
print([n * n for n in nums if n % 2 == 1])   # [1, 9, 25]
print({n: n * n for n in nums})
print({n % 3 for n in nums})
```

嵌套推导可读性差时，改回普通 `for`。

### 1.2 迭代器协议（知道即可）

`for x in xs` 的本质：取迭代器，反复 `next`，直到 `StopIteration`。

```python
it = iter([10, 20])
print(next(it), next(it))
```

### 1.3 生成器：惰性产出

函数里有 `yield`，调用时返回生成器，适合大文件边读边处理：

```python
def read_scores(path: str):
    with open(path, encoding="utf-8") as file:
        for line in file:
            line = line.strip()
            if line:
                yield float(line)


# for score in read_scores("scores.txt"):
#     print(score)
```

生成器表达式：

```python
total = sum(n * n for n in range(5))
print(total)
```

### 1.4 小结

小数据用列表推导；大数据或流水线用生成器。

## 2. 闭包与装饰器

### 2.1 闭包：带配置的函数工厂

```python
def make_threshold_filter(threshold: float):
    def passed(score: float) -> bool:
        return score >= threshold

    return passed


is_good = make_threshold_filter(0.8)
print(is_good(0.91))  # True
```

### 2.2 装饰器：统一加料

本质是「接收函数，返回函数」——适合日志、计时、重试：

```python
import functools
import time


def timed(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 耗时 {time.perf_counter() - start:.4f}s")
        return result

    return wrapper


@timed
def rank_cases(scores: list[float]) -> list[float]:
    return sorted(scores, reverse=True)


rank_cases([0.2, 0.9, 0.5])
```

`@functools.wraps(func)` 保留原函数名字和文档字符串。

### 2.3 带参数的装饰器

```python
import functools


def retry(times: int = 3):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_error = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except TimeoutError as exc:
                    last_error = exc
                    print(f"第 {attempt} 次失败: {exc}")
            raise RuntimeError(f"{func.__name__} 重试耗尽") from last_error

        return wrapper

    return decorator


@retry(times=2)
def fetch_output():
    raise TimeoutError("模型超时")


# fetch_output()  # 取消注释可观察重试
```

真实项目请收窄异常类型，并加退避，避免疯狂打接口。

### 2.4 小结

闭包记住配置；装饰器横向复用横切逻辑；记得 `wraps`。

## 3. 类型注解与 Pythonic 习惯

```python
from __future__ import annotations

from typing import Callable

ScoreFn = Callable[[str, str], float]


def run(cases: list[tuple[str, str]], scorer: ScoreFn) -> float:
    if not cases:
        return 0.0
    return sum(scorer(p, e) for p, e in cases) / len(cases)
```

注解帮助阅读和 IDE，不替代测试。更 Pythonic 的习惯：

- 用 `with` 管资源
- 用推导式表达清晰的映射 / 过滤
- 用 `Path`、f-string、dataclass
- 显式优于隐式：少依赖隐藏全局状态

## 4. 数据库入门：SQLite

程序结束时内存数据会消失。需要按条件查询、持久化评测结果时，可用数据库。

Python 标准库自带 **SQLite**（嵌入式，无需单独装服务器），适合本地实验：

```python
import sqlite3
from pathlib import Path

db_path = Path("eval.db")
conn = sqlite3.connect(db_path)
try:
    conn.execute(
        """
        CREATE TABLE IF NOT EXISTS results (
            case_id TEXT PRIMARY KEY,
            score REAL NOT NULL,
            model TEXT NOT NULL
        )
        """
    )
    conn.execute(
        "INSERT OR REPLACE INTO results(case_id, score, model) VALUES (?, ?, ?)",
        ("case-01", 0.92, "gpt-test"),
    )
    conn.commit()
    rows = conn.execute(
        "SELECT case_id, score FROM results WHERE score >= ? ORDER BY score DESC",
        (0.8,),
    ).fetchall()
    print(rows)
finally:
    conn.close()
```

要点：

1. 用 `?` 占位符传参，不要用 f-string 拼 SQL。
2. 写操作后 `commit()`。
3. 生产多用户并发再考虑 MySQL / PostgreSQL。

JSON 文件适合交换与归档；频繁条件查询时，SQLite 是本地第一选择。

## 5. 综合示例：迷你评测器

把三篇机制串起来：dataclass 用例、可替换打分函数、JSON 报告、`__main__` 入口。

```python
from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path
from typing import Callable


ScoreFn = Callable[[str, str], float]


@dataclass
class Case:
    case_id: str
    expect: str
    predict: str


def exact_match(predict: str, expect: str) -> float:
    return 1.0 if predict.strip() == expect.strip() else 0.0


def run_eval(cases: list[Case], scorer: ScoreFn) -> dict:
    details = []
    for case in cases:
        score = scorer(case.predict, case.expect)
        details.append({"id": case.case_id, "score": score})
    average = sum(item["score"] for item in details) / len(details)
    return {"average": average, "details": details}


def save_report(report: dict, path: str | Path) -> None:
    target = Path(path)
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_text(
        json.dumps(report, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )


if __name__ == "__main__":
    dataset = [
        Case("1", "通过", "通过"),
        Case("2", "拒绝", "我无法回答"),
    ]
    result = run_eval(dataset, exact_match)
    save_report(result, "output/report.json")
    print(result["average"])
```

可继续演进：

- 换成 `ContainsScorer().score`
- 用 `@timed` / `@retry` 包住模型调用
- 把结果额外写入 SQLite

## 6. 练习与学习路线回顾

### 6.1 练习

1. 写 `@retry(times=3)`，**只**捕获 `TimeoutError`，并打印第几次重试。
2. 用生成器逐行读取 JSONL 用例，边读边打分，不要一次性 `read().splitlines()` 也可以实现。

4. 把综合示例拆成包：`cases.py` / `metrics.py` / `runner.py`，保证能跑通入口。
