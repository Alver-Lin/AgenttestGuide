# FastAPI 全景地图：从第一个接口到可维护服务

**本篇目标**：给你一张 FastAPI 学习地图——按从易到难排好，覆盖把 HTTP API **真正写出来、调通、拆开维护** 所需的主干能力。

> 说明：FastAPI 文档极全，不必背完每一个参数。所谓会用，是指：
> 1. **能独立起一个服务**，用浏览器 / Apifox 调通接口；
> 2. **能正确接收路径、查询、请求体**，并用 Pydantic 做校验；
> 3. **能组织路由、依赖与错误处理**，做出一个小而完整的 CRUD 服务。
>
> 前置建议：具备 [Python 语言地基](../python/1-语言地基.md) 的函数与类型基础；了解 [RESTful 使用方法](../RESTful使用方法.md) 与 [Apifox 的使用方法](../Apifox的使用方法.md) 会让调试更顺。

---

## 总览：六层能力模型

```text
6  实战成绩管理 API     ← 能交付一个完整小服务
5  依赖注入与工程结构   ← 能拆分路由、复用依赖、挂中间件
4  响应与错误处理       ← 能约定返回形状、状态码与异常
3  请求体与校验         ← 能用 Pydantic 定义并校验输入
2  路由与参数           ← 能声明路径、方法与各类参数
1  快速入门             ← 能安装、启动、打开自动文档
```

由下往上：下面是地基，上面是楼层。每层对应一篇正文。

## 掌握标志

学完后你应能：

1. 用 `uvicorn` 启动服务，并在 `/docs` 中试调接口；
2. 正确区分路径参数、查询参数与请求体；
3. 用 Pydantic 约束输入，用 `response_model` 约束输出；
4. 对业务错误返回合适的 HTTP 状态码；
5. 用 `APIRouter` + `Depends` 拆分一个小项目，并用 Apifox 完成 CRUD 联调。
